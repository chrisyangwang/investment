## 4. 业务模式与护城河

**章首判断**：美的护城河在 ToC 段「规模制造+全品类渠道+品牌矩阵」最硬；ToB 段楼宇具备方案与后市场粘性；机器人段品牌与重载位势在，但利润率尚未证明可转化为集团 ROIC。

### 4.2 ToC 壁垒（智能家居）

1. **品牌矩阵**：美的 / 东芝 / COLMO / 华凌 / 小天鹅等覆盖高中低；高端放量（COLMO/东芝零售双位数）与华凌走量并存——份额与结构可同时做，但高端 ASP 持续性依赖产品迭代而非补贴。（年报+交银/华泰）
2. **渠道**：线上（含下沉）占智能家居内销 **55%+**；全渠道库存周转改善 **10%+**；数一战略下主流平台销售额第一。（年报）
3. **vs 格力/海尔**：格力空调专注、毛利/净利更高但品类窄、估值折价；海尔冰洗/高端/场景更强；美的胜在**品类广度+效率+全球化产能**。618 等大促显示美的总量份额领先但高端仍弱于卡萨帝系。（WebSearch 渠道对比，一手强度中）

**证伪条件**：内销份额一年内掉出第一阵营且无法修复；楼宇后市场停滞；库卡中国份额跌出前五且欧洲订单持续萎缩。

### 4.3 ToB 壁垒

- **楼宇**：iBUILDING 平台 + 暖通/电梯/楼控 + 后市场（2025 后市场服务收入超 20 亿、翻倍）；液冷 CDU/磁悬浮冷水机切入 AIDC；毛利率高于集团。（年报）
- **工业技术**：美芝压缩机等全球份额高；新能源车部件处价格战——「卖铲人」逻辑成立但利润率被卷。（年报+新闻）
- **证据强度**：合同能源管理、轨交、数据中心标杆项目可验证「设备→方案」转换；但集团层面 ToB 利润贡献升幅仍可能小于收入升幅。

### 4.4 机器人与自动化

- 库卡 2025：收入 **€38.97 亿**（+），订单 **€41.57 亿**，中国首次超 **€10 亿**；EBIT **€0.587 亿**，margin **1.5%**（重组费用 €0.75 亿拖累）。（KUKA AR2025）
- 中国出货超 3.2 万台、+30%+，份额 9.6% 前三；300kg+ 重载份额 47.4%。（年报/MIR）
- **并购协同**：自制率提升、中国产能与美的工厂密度（670 台/万人）是真实协同；欧洲盈利修复慢——**期权价值 > 当期利润贡献**。

### 4.5 可复制性

海信/格力可模仿单品促销与部分渠道政策，难在短期内复制：**全球 43 厂本地化网络 + OBM 自营 50 国 + 楼宇软硬一体 + 库卡品牌**。可模仿的是低价份额战；不可快速模仿的是海外服务网络与 ToB 项目交付体系。

## 5. 战略、渠道/全球化与管理层执行

**章首判断**：战略口号「高端化、全球化、ToB、数智化」中，**海外 OBM、楼宇、股东回报**已兑现为数字；**库卡利润率、新能源件、医疗**仍处「交学费」阶段。执行力评分：**优−**。

### 5.1 战略→数字映射

| 战略关键词 | 财报对应证据 |
|---|---|
| 全球化 / OBM 优先 | 海外收入 1959 亿(+16%)；OBM 占智能家居外销 **45%+**；自营国 27→50 |
| ToB 第二曲线 | ToB 相关 ~1228 亿(+17.5%)；楼宇 +25.7% |
| 效率优先 / 简化 | 销售费用率 9.35%；2026Q1 销售费用率同比下降 |
| 股东回报 | 2025 分红+回购 **>** 归母净利；2026 拟回购 65–130 亿且拟注销 |
| AI / 数智 | 灯塔工厂、MevoX、液冷基地；研发费用率 ~3.9% 稳态 |

### 5.2 产品与定价 / 渠道

- 以旧换新 2024–25 抬升内销基数；2026 排产转弱、库存高位——**份额-利润权衡进入「控产去库」阶段**。（产业在线/东方，WebSearch）
- 美的渠道政策（库存可退换、返利上调）利于份额，但短期费用与均价承压——传导链：排产↓→去库→价格纪律修复→毛利率企稳（需 2–3 个季度验证）。

### 5.3 管理层与资本配置（management_quality_check_skill）

- 方洪波体系：多层股权激励（九期期权、七期限制性股票、十六期持股计划等）；强调「白色家电和空调是核心，工业机器人与新能源是次核心，其他能打就打」。（股东会新闻，2026-06）
- **资本配置纪律**：高分红+大额回购注销 = 股东友好；同时 CapEx/并购抬升（海外本地化、Arbonia 等）→ ROIC 有稀释风险。
- 库卡事后审计：收入与中国份额改善兑现，**EBIT 1.5% 远低于收购时隐含回报**——协同在「能力」而非「利润率」。

### 5.4 执行监控指标（未来 24 个月）

1. 内销空调份额与出厂均价 / 渠道库存（美的渠道库存）
2. 外销毛利率与 OBM 占比
3. 楼宇收入增速与毛利率、液冷订单
4. 库卡 EBIT margin（目标观察是否回升至 3–5%）
5. 回购进度与分红率（是否维持「分红+回购≈净利」量级）

**章首判断**：利润表质量高、现金牛属性强；绿旗多于红旗。红旗聚焦：**存货与渠道库存、经营现金流同比回落、商誉 343 亿、ToB/机器人低 ROIC 拖累集团回报率下行**。

## 7. 分业务拆解（家用 / ToB / 机器人）

### 7.1 智能家居（ToC）

- **结构**：内销靠更新与份额；外销靠 OBM+本地化。空调是利润核心，冰洗厨小电贡献规模与协同。
- **2026 机制**：排产同比转负（4 月空冰洗合计排产 −3.6%；6 月空调排产大幅下滑）→ 出货/收入增速下台阶；若去库顺利，下半年价格纪律修复。（WebSearch：江海/东方）
- **2028 中性**：收入 CAGR ~4–6%（份额+结构，不靠大盘反弹）；经营利润占集团 **~72–75%**。
- **敏感因子**：内销均价 ±2%、外销汇率 ±3%、份额得失。

### 7.2 ToB（楼宇 + 工业技术 + 其他创新中的 ToB）

- **楼宇**：增速与毛利双优；数据中心液冷是 2026–28  clearest alpha；后市场提升粘性。**应享受估值溢价**，但需利润额兑现而非仅收入。
- **工业技术**：272 亿，+10%；压缩机稳健，新能源件价格战 → 增收不增利风险。2026Q1 工业技术收入 −11.7%（券商拆分）——周期下行已现。
- **2028 中性**：ToB（含楼宇+工业+相关）收入占比升至 **~28–31%**；利润贡献占比 **~22–25%**（低于收入占比）。
- **敏感因子**：楼宇毛利率 ±100bp、工业技术收入 ±10%。

### 7.3 机器人与自动化（含库卡）

- 收入 310 亿，毛利率 ~21%；库卡集团 EBIT 1.5%——**并表利润贡献有限**。
- 扭亏叙事需改写为「利润率爬坡」：观察 2026–28 EBIT 是否走向 3–5%。中国区强、欧洲弱。
- **人形/伏羲**：研发期权，2028 前不对集团净利建模为主要贡献（turnaround_story_validation_skill：**未通过「利润反转」检验，仅通过「订单/份额改善」检验**）。
- **2028 中性**：收入占集团 ~7%；经营利润占比 **~3–5%**；市值贡献以期权计 **300–500 亿**（非按 Fanuc 倍数）。
- **敏感因子**：库卡 EBIT ±2ppt、商誉减值。

### 7.4 其他

其他创新 287 亿（+27%）含医疗等；管理层称「能打就打、打不了就跑」——估值上作 **零溢价**，避免干扰主业倍数。

## 8. 行业位势与竞争格局

**章首判断**：白电进入「高库存、弱排产、份额博弈」阶段；出口与 ToB 是美的相对格力的差异化；机器人是长周期期权。

### 8.1 家电结构与竞争

- 利润池仍在空调；冰洗看高端与出口。地产竣工代理权重下降，**更新需求+政策脉冲**主导内销波动。
- 三角：格力（空调盈利）/ 海尔（高端场景）/ 美的（综合效率全球化）。价格战触发：库存>阈值阈值且头部开盘让利；结束信号：排产连续低于出货、渠道库存同比转负、返利回落。

### 8.2 出口与全球

中国白电出海份额提升；美的长板是本地化产能与 OBM，短板是欧美品牌心智仍弱于本土龙头。关税情景：本地化对冲部分原产地风险，但折旧与合规费用侵蚀净利率（Base 不假设海外净利率大幅抬升）。

### 8.3 ToB / 机器人行业

- 中央空调国内 2025 下滑，但数据中心/公建结构性机会。
- 工业机器人：汽车 CAPEX 周期 + 一般工业渗透；国产替代压中低端价格；库卡靠重载与集成差异化。

### 8.4 未来 3 年行业关键变量 Top5（传导路径）

1. **空调渠道库存** → 排产/均价 → 美的毛利率与费用率  
2. **以旧换新政策强度** → 内销量 → 收入增速  
3. **铜铝价格** → 成本时滞 1–2 季 → 毛利率波动  
4. **AIDC 液冷资本开支** → 楼宇订单 → ToB 利润  
5. **汽车/一般工业自动化 CAPEX** → 库卡订单与 EBIT

## 10. 市场预期差（核心）

**章首判断**：股价已从 2026 初 ~79 元上行至 **84.16**，部分修复「低估红利」叙事；当前更像定价了 **中性情景的 60% + 乐观叙事的 20%**，对去库长尾与库卡利润率仍定价不足。预期差方向：**上行（有限）** → **标配至适度超配**。

### 10.1 共识地图

- **评级**：近端覆盖以「买入」为主（开源/国盛/国金/西部/交银/华泰等）。
- **目标价**：综合值约 **94–96 元**（iFind 2026-06）；华泰一度给 99.5（26E 16×）——偏乐观倍数。
- **一致预期净利**：2026E ~470 亿，2027E ~509 亿（Wind）。
- **隐含假设（从研报反推）**：内销平稳软着陆、外销双位数可维持一段时间、ToB 继续快于 ToC、库卡「改善中」、分红回购提供估值底。

### 10.2 市场定价隐含

- T0 PE(预测) **13.65×**、股息率 **5.0%**。
- 粗略 Gordon：若 r=9.5%，股息率 5% 隐含长期 g≈4.5%——与「白电稳态+有限 ToB」一致，**未 implicit 定价 8%+ 永续增长**。
- 反向 DCF：要支撑 6,400 亿市值，需 FCF 稳态增长中个位数 + 终值倍数合理——与 Base 相容。
- 相对格力溢价 ~90%+：含治理/增长/全球化；若仅剩「分红差」，溢价应收窄。
- AH：A 略折价于 H，显示海外投资者对美的全球化溢价认可度不低。

### 10.3 预期差分项清单

| 议题 | 市场隐含 | 本文判断 | 方向 | 对 2028E 利润 | 对倍数 | 证据 |

| 外销增速与毛利 | OBM 带动毛利明显抬升 | 收入可增，净利率仅 **持平略升** | 中性 | ±5 | 有限 | CapEx/本地化费用 |
| ToB 利润率上台阶 | 收入占比升→PE 升至 15–16× | 楼宇是真 alpha；整体 ToB **利润占比落后收入** | 分化 | +10（楼宇）/−5（工业） | +0.5× 仅当楼宇兑现 | 年报毛利结构 |

### 10.4 拥挤与博弈

- 标签博弈：若市场切回「纯白电」，PE 向 11–12× 压缩，需利润增长补偿；若切「AIDC 楼宇」，局部重估。
- 资金：ETF/被动占比升，主动抱团程度低于白酒龙头——挤兑风险低于核心资产泡沫期。

### 10.5 催化剂与证伪时钟（未来 4 个季度）

| 时点 | 验证/打脸 |
|---|---|
| 2026 中报 | 分部毛利、库卡、存货周转、回购进度 |
| 月度排产 | 空调内销排产是否转正、库存同比 |
| 同业开盘价 | 格力/美的返利与开盘价纪律 |
| 库卡披露 | EBIT margin、中国订单 |
| 液冷基地/订单 | 楼宇 AIDC 兑现度 |

### 10.6 多空论证（bull_bear_case_builder_skill）

**多头最强 5 条**  
1. 份额与全品类效率壁垒 → 若错：份额战变成价格战，毛利率 −100bp+。  
2. 海外 OBM+本地化 → 若错：关税与折旧吞噬净利。  
3. 楼宇/液冷高增长高毛利 → 若错：项目延期、竞争加剧。  
4. 分红+回购提供 5%+ 现金回报底 → 若错：FCF 下滑迫使降分红。  
5. 相对历史与板块分位不高 → 若错：盈利下修导致「分位陷阱」。

**空头最强 5 条**  
1. 渠道库存高、排产弱 → 若错：旺季去库超预期。  
2. 2026Q1 扣非差 → 若错：一次性汇兑，下季修复。  
3. 库卡低 EBIT+商誉 → 若错：重组结束、margin 回升。  
4. ROIC 被 ToB/CapEx 稀释 → 若错：楼宇利润释放抬回报。  
5. 相对格力溢价过大 → 若错：美的增长差持续证明溢价。

### 10.7 预期差结论（强制句）

当前股价更像定价了**中性情景的大部分现金牛价值 + 小部分 ToB 乐观**，因此预期差方向是 **上行（有限）**，主仓位含义是 **标配至适度超配**。

## 11. 估值方法、T0 判断与 2028 三情景市值建议

### 11.1 方法选型（valuation-pricing-framework）

| 方法 | 角色 | 理由 |

### 11.4 反向 DCF 要点（dcf-model / china-dcf）

假设 WACC 8.5–9.5%，永续 g 3.5–4.5%，稳态净利率 ~9.5%、FCF/净利 ~0.85：现价大致嵌入 **中性增长路径**；要到达乐观市值需同时上修利润与压缩 WACC（或抬终值倍数）——即「叙事溢价」。

### 11.5 2028 年三情景市值建议（硬性交付）

| 情景 | 2028E 净利(亿) | 目标 PE / SOTP | **2028 目标市值** | 较 T0(6418亿) | 关键假设一句话 |

**隐含年化复合回报（至 2028 年末，约 2.5 年）**  
- 中性市值空间 +17% → 价格年化 ~6.5%，加股息 ~5% → **总回报约 11–12%**

## 1. 投资摘要（一页纸）

**核心判断**：泡泡玛特不是「玩具店」，也不是「单一 Labubu 故事股」，而是 **自有艺术家 IP 矩阵 + 全球 DTC（直营店/机器人/线上）** 的潮玩运营商。2025A 用极端年份证明了「无影视内容亦可打出全球百亿级 IP」与罕见盈利质量（毛利率 72.1%、净利率 35.1%、OCF 108.7 亿），但 **THE MONSTERS（Labubu）占比 38.1%、存货 +259%、海外增速从爆发期回落、管理层主动把 2026 定为「休整优化年（收入 ≥20%）」**——说明 2025 是峰值年份而非新常态。

**预期差方向**：**温和上行 / 近似充分定价偏 Base**。当前股价更像定价了「增速换挡 + 净利率从 35% 回落、但未崩盘」的中性偏审慎情景，尚未充分定价「非 Labubu 矩阵接力成功 + 内容化延长 IP 寿命」的乐观尾部，也未充分定价「存货减值 + Labubu 硬着陆」的悲观尾部。

**仓位含义（买方语言）**：**标配**；若股价回落至隐含更接近悲观情景的区间可 **逢低适度超配**；若在无基本面验证下快速冲高至乐观情景定价则 **降为低配**。

**中性情景 2028 市值建议中枢：约 2,530 亿港元（区间约 2,270–2,780 亿港元）**；乐观中枢约 **4,240 亿港元**；悲观中枢约 **790 亿港元**（汇率：1 HKD≈0.866 CNY）。

**一句话风险**：头部 IP 热度退潮且新品接力失败 → 收入与 PE 双杀；存货堰塞湖兑现减值。

## 3. 公司速写与 T0 估值快照

### 3.1 公司是什么（`stock_first_look_skill` / `hot_stock_quick_read_skill`）

- **业务**：IP 孵化与运营 → 潮玩产品（盲盒/手办/毛绒/MEGA/衍生品）→ 全渠道零售（直营店、机器人、线上、批发）→ 体验（乐园等）。
- **为何火**：2024–2025 Labubu 全球社媒病毒 + 海外 DTC 复制，把公司从「中国潮玩龙头」推成「全球情绪消费稀缺标的」。
- **市场在赌什么**：Labubu 是长寿 IP 还是时尚爆款；净利率 35% 能否外推；海外是增收增利还是费用吞噬。
- **最易错在哪**：把 2025 峰值外推为中枢；把二手溢价当一级需求；把「海外毛利率高」线性等同「海外净利率永续更高」。

## 5. 战略、渠道/全球化与管理层执行

**章首判断**：战略关键词「IP 全球化、全渠道、休整优化」已部分兑现为数字；2026 的关键不是口号，而是 **海外店效、存货周转、非 Labubu 增速** 三张成绩单。

### 5.1 战略→数字映射

| 战略表述 | 已执行结果（2025A / 2026Q1） | 评价 |
|---|---|---|
| IP 全球化 | 海外收入 43.8%；美洲 +748%；德/丹/加/菲首店 | 0→1 成功；1→N 进入费用与本地化硬仗 |
| 全渠道 | 零售 46.5% + 线上 44.3%；机器人补点 | 线上高占比提升效率也放大折扣/物流风险 |

### 5.2 渠道与同店质量

- 中国 2025 门店净增仅 **14** 家（431→445），收入仍 +134.6% → **更多是店效/结构（IP+毛绒+线上）而非开店叙事**（绿旗）。
- 全球净增 109 店，海外扩张为主；美洲门店快速爬坡（Wind 业务数据示美国市场门店数量级从几十家级扩张）。
- 2026Q1：中国线上 +150–155%、线下 +75–80%（公司自愿公告）→ 中国内生仍强；亚太仅 +25–30% → **海外从爆发期进入着陆期**。

### 5.3 管理层与资本配置（`management_quality_check_skill`）

- 股权：GWF Holding **41.78%**（王宁相关），控制权集中；管理层深度绑定 IP 方向。
- 分红政策：拟不少于可分派净利 **20%**；2025 现金分红相关披露约 **36.5 亿人民币** 量级（iFind 事件字段）。
- 回购：2024–2026 累计回购金额口径约 **18.3 亿人民币**（Wind events）；2025 初至 2026-07 回购约 **17.4 亿港元 / 1,122 万股**（iFind）——对 EPS 有被动增厚，也对情绪有托底。
- 现金：2025 末现金及等价物 **137.8 亿人民币**；有息债压力低（bond 不适用）→ **再投资与回购空间充足**。
- **执行力评分：优（结果）/ 中（节奏）**——打出全球爆款与利润率属优；对峰值管理与库存前瞻属中。

**未来 24 个月监控指标（优先）**：① THE MONSTERS 收入占比；② 非 Labubu Top IP 合计增速；③ 存货周转天数；④ 海外收入增速与店效；⑤ 综合毛利率；⑥ 经营现金流/净利；⑦ 会员复购；⑧ 港股通/主动基金持仓变化。

## 7. 分业务拆解

### 7.1 盲盒 / 潮玩零售（抽盒主业）

- 收入主体仍是产品零售（渠道加总≈全公司）。盒单价/ASP 随毛绒与海外结构上升而抬升（定性，年报未单列统一 ASP）。
- 中国会员复购 55.7% 是稳态需求底座。
- **2028 中性**：仍贡献集团收入主体（≈85%+ 收入来自产品零售口径）；经营利润贡献随毛利率回落而占比略降。
- **敏感因子**：同店/店效、折扣率、抽盒转化、机器人点位产出。

### 7.2 IP 运营与授权 / 联名

- 自有艺术家 IP 占收入 90%；授权 IP 9.1%。
- 「其他收入」中的授权费及其他服务 2025 仅 **0.71 亿**——**授权不是利润主引擎，零售才是**。
- 头部集中：Labubu 家族是胜负手；Molly 证明「占比可降、绝对额可长尾」。
- **2028 中性假设**：THE MONSTERS 绝对收入平台化至约 **90–110 亿**，占比约 **18–22%**；其余矩阵补位。
- **敏感因子**：Labubu ±20% 收入；新品命中率；艺术家续约。

### 7.3 海外业务

- 2025：162.7 亿、占比 43.8%；是估值「成长溢价」的主要来源。
- 2026Q1 增速回落（亚太 +25–30%、美洲 +55–60%、欧洲 +60–65%）验证着陆。
- 管理层与券商：2026 强化官网/会员、线下占比目标略升；美洲团队扩张（海通：美洲门店 72 家量级、团队近 2000 人——研报口径）。
- **是否应享估值溢价**：仅当海外 **店效覆盖租金/人工/物流** 并贡献净利率 ≥22% 时给溢价；否则按中国稳态折扣。
- **2028 中性**：海外收入占比 ≈**48–52%**；海外分部净利率 **22–26%**（低于爆发期表观）。

### 7.4 线上 / 机器人 / 其他

- 线上占比高（尤其美洲线上占比高——券商/媒体口径）→ 对社媒算法与价格纪律敏感。
- 机器人：中国密度高，单点产出低于旗舰店，但是低成本触达与品牌渗透工具。
- **互蚕风险**：线上折扣可能冲击线下心智；需看综合毛利率与会员 ARPU。

### 7.5 乐园 / 体验 / 衍生品

- POP LAND 与 IP 体验是品牌放大器；交银称北京乐园新区超预期。
- Capex 与引流属性为主，**Base 不将其记为重要利润中心**；Bull 可给期权。

### 7.6 2028 中性贡献示意（合并口径推演）

| 模块 | 2028E 收入贡献（示意） | 经营利润贡献（示意） | 上行/下行敏感因子 |
|---|---:|---:|---|
| 中国产品零售 | ~48% | ~50% | 同店、会员复购 |
| 海外产品零售 | ~48% | ~45% | 店效、物流、关税 |
| 机器人 + 批发等 | ~4% | ~3% | 点位产出 |
| 乐园/授权等 | ~少量 | ~少量 | 电影/乐园客流 |

## 8. 行业位势与竞争格局

**章首判断**：利润池在 **IP 方（原创与运营）** 而非纯渠道货架；二手市场短期是放大器、中期是破坏器；出海胜负在本地化 DTC，而非出口批发。

1. **结构**：盲盒提供转化与娱乐属性；毛绒/手办提供社交与收藏；集合店与电商货架分流价格带。
2. **竞争**：名创联名抢货架；TOP TOY/52Toys 抢国内潮玩；国际授权玩具品牌抢欧美货架。泡泡玛特差异化在 **原创 IP 命中率 + 会员社群**。
3. **需求迁移**：从「抽盒赌博快感」部分迁移到「IP 生活方式」——对 Labubu 电影/乐园是利好，对纯炒作是利空。
4. **监管**：2023《盲盒经营行为规范指引》要求概率披露与未成年人保护；执行仍有温差。对头部合规品牌影响更多是 **获客摩擦与舆情**，而非立刻消灭模型（证据：公司已公示概率与年龄提示）。
5. **位势**：IP 矩阵深度 **高**、渠道网络 **中高**、海外渗透 **中（快速提升）**、社群强度 **高**。
6. **未来 3 年行业 Top5 变量→利润传导**：① 爆款生命周期；② 二手溢价→一级转化；③ 海外店效；④ 存货与折扣；⑤ 监管/未成年人合规成本。

## 10. 市场预期差（核心）

**章首判断**：杀估值的主因已发生（指引换挡 + Labubu 降温叙事）；当前主分歧从「高成长是否永续」转为 **「中性利润中枢在 140 亿还是 200 亿」** 与 **「该给 13× 还是 20×」**。

### 10.1 共识地图

- **目标价**：Wind 综合 ≈**238 港元**；iFind 近月综合值约 **210 港元**；绩后大行大幅下调（例：美银 170 / 中金 248 / 富瑞 228 / 高盛 184 / 瑞银 278 等，媒体综合）。分布极宽 → **多空撕裂**。
- **隐含假设（从研报反推）**：多数买方/卖方 Base 仍假设 Labubu 软着陆、海外继续贡献、毛利率仅小幅下滑；空头（德银等）则假设海外热潮结束、收入接近零增甚至负增。
- **评级**：Wind「增持+」；但已出现买入→中性的下修（美银等）。

### 10.2 市场定价隐含

- T0 PE_fwd **12.8×** × 本文 Base 2026E EPS≈10.0 元 ≈ 股价与盈利大致咬合（汇率折算后）。
- 相对 2025A 峰值利润，市场拒绝给成长溢价；相对 2028E 若用卖方 200 亿净利，则现价仅约 **10–11× 2028E**——**看起来很便宜，但前提是 200 亿成立**。
- 若用本文 145.8 亿，则现价约 **13.0× 2028E（人民币市值口径）**——接近「换挡后消费成长股」中枢，**不是深度低估**。

### 10.4 拥挤与博弈

- 港股通持股占比字段约 **24.6%**（Wind）——南向仍重要。
- 基金重仓：Wind 样本显示部分主动基金对泡泡玛特持仓减少（如部分产品从上期重仓下降）——**拥挤交易有所松动**，利空出尽与流动性变差并存。
- 博弈：若基本面只是「换挡」而非「崩盘」，低拥挤 + 低 PE 可产生修复；若单季验证崩盘，低拥挤也挡不住杀估值。

### 10.5 催化剂与证伪时钟（未来 4 个季度）

1. **2026 中报**：海外分部增速/利润、存货周转、THE MONSTERS 占比。
2. **大单品发售与二手价**：Labubu 新系列是否破发常态化（代理需求强度，非收入事实）。
3. **美洲同店/信用卡消费代理**（卖方跟踪口径）与官网会员指标。
4. **回购执行节奏**与分红。
5. **电影/乐园**进展（偏 Bull 期权）。

### 10.6 多空论证（`bull_bear_case_builder_skill`）

**最强 5 条多头**  
1. 利润率与现金流全球稀缺 → 即便增速下台阶，15× 可支撑。若错：利润率快速回到 20% 以下。  
2. 非 Labubu 矩阵已现（美国非 Labubu≈50%）→ 市场过度「单 IP 化」定价。若错：非 Labubu 增速不足以弥补。  
3. 中国少开店高增长显示需求质量。若错：2026 高基数下中国也失速。  
4. 净现金 + 回购提供下行保护。若错：回购无法对冲盈利下修。  
5. 内容化（电影）可能延长 IP 寿命。若错：电影延期或反响平淡。

**最强 5 条空头**  
1. 2025 不可复制；任何「高增外推」都错。若错：矩阵再造第二增长曲线。  
2. 存货堰塞湖可能减值。若错：开店消化库存、周转改善。  
3. 海外从流量到经营的转换失败。若错：本地会员体系建设成功。  
4. 毛绒供给扩张摧毁稀缺与 ASP。若错：正价需求仍稳。  
5. 即便业绩达标，标签切换使 PE 继续压缩。若错：消费风险偏好回升。

### 10.7 预期差结论（强制格式）

**当前股价更像定价了「中性情景偏下沿（利润率回落 + 增速换挡）」；因此预期差方向是温和上行 / 近似充分定价，主仓位含义是标配（逢回撤可超配，不追乐观定价）。**

## 11. 估值方法、T0 判断与 2028 三情景市值建议

### 11.1 方法选型（`valuation-pricing-framework`）

| 方法 | 角色 | 理由 |
|---|---|---|
| **PE（2028E）+ 增长质量** | **主方法** | 盈利已规模化；对增速下台阶最敏感，适合换挡期 |
| **SOTP（中国稳态 + 海外期权）** | **辅方法 1（强烈建议）** | 检验市场是否把海外溢价算错 |

**中性情景 2028 市值建议中枢为约 2,530 亿港元（区间约 2,270–2,780 亿港元）**；乐观中枢约 **4,240 亿港元**；悲观中枢约 **790 亿港元**。相对 T0≈2,189 亿港元，中性仅温和上行空间——**好公司、极端年份之后、估值已杀、但不是深度低估**。

## 13. 投资结论与仓位含义

1. **商业模式优质但周期属性强**：IP 工厂 + DTC 是真壁垒；爆款生命周期是真约束。  
2. **2025 峰值不可外推**：Base 把净利率从 35% 降到 27%，2028 净利约 **146 亿人民币**，显著低于多数卖方 200 亿假设。  
3. **估值**：主方法 PE，辅以 SOTP 与 DCF；中性 **15×** → **≈2,530 亿港元**。  
4. **预期差**：温和上行 / 近似充分定价；不是「必涨的深度价值」，也不是「必须清仓的泡沫」。  
5. **仓位**：**标配**；严格遵守清仓红线（Labubu 硬崩 + 存货爆雷 + 海外同店崩塌等）。

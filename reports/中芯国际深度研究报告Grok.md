## 摘要（≤800字）

**一句话投资论点**：中芯国际是大陆规模最大的纯晶圆代工平台，2025年利用率93.5%、收入673亿元、全球纯代工第二的地位真实；但 T0 **A股143.77元 / 总市值约12,308亿元 / PE(TTM)244× / PB6.46×**（Wind，2026-07-27）已把「高利用率+本土订单锁定+先进节点期权」计价到极致，中性2028市值约**6,800亿**、概率加权约**6,490亿**，仓位含义为**回避/轻仓观察**，等待倍数压缩或利润大幅超预期。

**核心预期差（3条）**  
1. **倍数**：Wind一致预期2028E净利约93.5亿元→现价隐含约**131×**；本报告中性目标倍数显著低于现价隐含，差在战略溢价能否外推。  
2. **率**：市场/部分卖方隐含毛利率在折旧+30%下仍可守住20%+；本报告中性2026–28毛利率约20.5%/19.5%/20.0%，拒绝“涨价永远覆盖折旧”。  
3. **量**：利用率高位基本被验证（2025A 93.5%、1Q26 93.1%）；预期差不在量能否维持，而在**增量产能转固节奏**与**先进制程天花板（管制不确定性）**。

**关键风险（3条）**：出口管制/实体清单对设备与备件的约束（财务映射：产能爬坡时滞、Capex效率折扣、先进节点停滞）；折旧同比+30%指引下毛利率承压；A/H极端溢价与科创板Beta压缩。

**估值方法**：主用 **2028E前瞻PB**（利润被高折旧扭曲，ROE仅约3–5%时PE失真）；辅EV/EBITDA与降权远期PE；DCF因负FCF与终值过高而低权重；台积电仅作行业参照并大幅折价。

## 1. 公司与商业模式拆解
**一句话结论**：价值创造链路是「Fabless/IDM下单→工艺导入认证→良率爬坡→晶圆出货（产能×利用率×ASP/Mix）→回款→高Capex再投资」，利润对**利用率与折旧**高度非线性敏感。

（技能：业务模式拆解 / china-unit-economics / 初识个股框架）

### 1.1 价值创造链路
客户需求（消费电子/手机/工控汽车/AI配套）→ 工艺平台认证 → 试产/良率 → 量产交付 → ASP×出货 → 收入确认与回款 → Capex扩产 →（多数年份）负FCF。  
纯代工特殊性：高固定成本；利用率对毛利率非线性；折旧滞后于Capex；客户切换成本高；节点世代锁定。

### 1.2 收入结构（2025A，来源：2025年报）
| 项目 | 数值 | 备注 |
|------|------|------|
| 营业收入 | 673.23亿元（$93.27亿） | +16.5% YoY（CNY）/+16.2%（USD） |
| 晶圆代工收入 | 约627.9亿元 | 占主营约94%+ |
| 中国区/美国区/欧亚区 | 85.6% / 11.6% / 2.8% | 地区收入占比 |
| 消费电子/手机/电脑平板/工汽/互联可穿戴 | 43.2%/23.1%/14.8%/11.0%/7.9% | 应用占比 |
| 12英寸/8英寸 | 77.1% / 22.9% | 尺寸收入占比 |
| 综合毛利率 | 21.6%（CNY）/21.0%（IFRS USD） | 同比+3pct |
| 归母净利 / OCF | 50.41 / 200.81 亿元 | OCF/净利≈4.0（折旧支撑） |

**单位经济（估计）**：2025年折合8英寸出货969.7万片，ASP约**USD 907/片**（产业/TrendForce口径，估计；同比由约933下行）。单片毛利随利用率与Mix波动；利用率每±5pct对毛利率弹性约**1.5–3pct**（估计区间，需季度验证）。

### 1.3 披露边界（强制）
公司自2022年起**不再按FinFET/28nm等节点披露收入占比**，改为尺寸/应用/地区口径。因此本报告对「相对先进制程」占比用**12英寸结构+券商估计+管理层表述**近似，并标注不确定性；**禁止把未披露节点良率/客户份额小数当作事实**。

### 1.4 本章结论
- 商业模式=高固定成本代工；利润引擎=利用率×ASP/Mix−折旧。  
- 中国区主导（85%+），本土订单锁定是护城河也是集中度风险。  
- 单位经济可估但节点级ASP未披露。  
- **可证伪**：若中国区占比显著回落且利用率不降，则“本土替代主叙事”需修正。


### 1.5 收入模式细节
- **直销为主**：年报披露直销模式收入与主营基本一致。  
- **配套**：光掩模、设计服务与IP、先进封装布局（先进封装研究院、芯三维）尚非利润主角，但是客户粘性增强项。  
- **价格机制**：代工报价按工艺平台/层数/特殊工艺加成；2026管理层称将“逐步涨价”，时滞在Q2–Q4（光大26Q1点评）——属于可验证催化。

### 2.5 侵蚀路径推演（3年）
1. **华虹/晶合等扩产**：在28nm及以上逻辑与特色工艺抢份额，压制ASP。  
2. **成熟节点全球供给**：若联电等扩产且需求走弱，价格战外溢。  
3. **管制**：先进节点停摆使“稀缺溢价”证伪，A股杀估值优先于杀利润。  
4. **估值自身**：即使基本面平稳，PE从240×向80×回归也会主导回报。

## 2. 业务与壁垒（护城河）
**一句话结论**：护城河为**「大陆相对先进代工稀缺性 + 成熟/特色平台规模」双层结构**，宽于华虹但远窄于台积电；出口管制同时强化国内锁定与削弱技术天花板。

（技能：护城河评估 / china-competitive-analysis）

| 维度 | 评分(1-5) | 证据 |
|------|-----------|------|
| 工艺平台广度与相对先进节点 | 4 | 0.35μm–14nm及以下；N+1类工艺有公开讨论但**良率/产能未精确披露（不确定性高）** |
| 客户认证与切换成本 | 4 | 大陆头部设计公司导入深；中国区85.6% |
| 产能规模与交付 | 5 | 月产能105.9万片（8"等价，2025末）；全球纯代工第二 |
| 供应链适配（受限环境工程能力） | 3 | 能维持高利用率，但设备依赖出口许可；**管制不确定性=核心变量** |
| 成本曲线与定价权 | 3 | 1Q26 ASP QoQ+2.5%（光大）；相对台积电无定价权，相对国内有议价 |
| 特殊工艺卡位 | 4 | BCD/嵌入式存储/RF-SOI/CIS等平台持续迭代（年报研发披露） |
| 出口管制对护城河 | 双向 | 强化国内订单锁定(+); 削弱先进节点与成本曲线(−) |

**综合**：护城河**中等偏宽，但正在被「折旧—管制」双向挤压技术溢价**。未来3年最可能侵蚀来源：①华虹等成熟节点份额与价格；②出口管制导致先进节点停滞；③利用率周期回落证伪高估值。

**H1裁决**：**部分成立**（证据强度：高）。壁垒=国内稀缺性+规模，而非全球成本最优。

## 3. 经营战略与执行
**一句话结论**：战略清晰——扩12英寸、提利用率、推特色平台、整合北方/南方股权；执行力**中上**，但Capex纪律服从设备交期与管制约束。

（技能：管理层体检 / 增长质检）

- **目标vs实际**：2025利用率93.5%（同比+8pct）、收入+16%+，符合“高于同业平均增速”方向；2026指引收入增速高于可比同业均值、Capex大致持平（公司业绩会/年报）。  
- **Capex**：2025年约**81亿美元**（公司披露）；购建固定资产等现金约600亿元人民币量级（年报现金流）。2026预计持平，但赵海军提示设备“长短脚”可能使**实际形成产能慢于设备到货**（OFweek/业绩会，访问日T0）。  
- **股权与治理**：无单一实控人；大唐/大基金等国资与产业基金影响显著；推进中芯北方少数股权收购、中芯南方增资（交银/华安等研报）。分红历史极低/无实质分红，资本配置=再投资。  
- **执行力评分**：**中上**。高利用率兑现强；先进节点推进受管制约束，不可线性外推。


### 3.1 十大重点任务与财务映射
年报致股东信提出2026十大重点（守安全、抓项目、强技术、拓增量等）。映射到模型：  
- 抓项目/拓增量 → 收入与利用率假设上沿；  
- 控成本 → 费用率与材料动力；  
- 防风险/应变局 → 对应出口管制情景权重；  
- 强技术 → 相对先进制程期权，但**不得无证据上调利润**。

### 3.2 过去五年轨迹一句话
2021–22高利润率周期 → 2023利用率与利润双杀 → 2024量修复但毛利率探底 → 2025量价利用率共振修复。当前类似“修复后的平台期”，不是新一轮利润率趋势向上的起点。

- OCF/净利润 2025≈4.0：折旧支撑现金流，**利润质量≠自由现金质量**。  
- 有息负债2025约886亿元（Wind）；净负债随扩产上升（光大模型显示净负债扩大）。  
- 政府补助2023–25约16.8/13.3/15.8亿元，占税前利润不可忽视，三情景假设温和退坡。  
- 少数股东损益2025约21.7亿元，北方收购后归母占比有望提升（交易落地进度=跟踪项）。

### 5.4 回报
ROE 3.4%、ROIC低个位数：相对华虹（ROE<1%）略好，相对联电/台积电显著差。**高Capex期ROIC<WACC**是常态。

### 5.5 五大财务事实
1. 利用率从周期底部修复至93%+，是利润弹性主因。  
2. 折旧/收入约四成，2026还将+30%。  
3. FCF持续大幅为负（光大估2025 FCF约−81亿美元量级）。  
4. 中国区收入>85%，客户与地缘集中。  
5. A股244×TTM与ROE3%严重背离。

**财务健康评级：观察**  
**H3裁决**：**成立**（高）。利润弹性对利用率与折旧更敏感，其次ASP/Mix。  
**H5裁决**：**部分成立**（高）。OCF强、FCF负；“收入高增、折旧吞噬、现金承压”成立。  
**H6裁决**：**成立**（高）。再投资优先，股东回报弱，存在股权整合/增资稀释路径。


### 5.6 利润率分解（强制尝试）
```
净利率变化 ≈ 毛利率变化 − 费用率变化 − 减值/其他 ± 税收/汇兑/补助
毛利率变化 ≈ 利用率杠杆 + ASP/Mix − 折旧上升 − 材料动力 ± 其它
```
2024→2025：毛利率+3.0pct，净利率约+1.4pct（年报）。利用率+8pct是主因；折旧大幅增长构成对冲项。  
2025→2026E（中性）：折旧+30%约贡献毛利率**−2至−4pct**的压力；若ASP/Mix与利用率仅能贡献+1至+2pct，则毛利率落到约20%附近——与指引中枢一致，**没有额外安全垫**。

### 5.7 冗余利润检测（不可外推项）
- 政府补助脉冲（年约14–17亿）不可按净利高增速外推。  
- 汇兑损益（记账本位币美元）在人民币波动年扰动净利。  
- 利用率周期高点（95%+）不可当作稳态中枢；新产能投放天然降低短期利用率分母。  
- 少数股东损益结构随北方收购变化，历史归母占比不可直接外推。

## 6. 行业特点与竞争格局
**一句话结论**：全球代工呈“先进向台积电集中、成熟节点供需再平衡”；中芯的超额订单来自**本土回流+AI配套虹吸**，而非赢得全球先进节点份额。

（技能：china-sector-overview克制使用 / 同业比选）

传导机制（反套话）：终端库存→下单→利用率（1–2季滞后）→ASP→毛利率。2026年台积电削减部分28nm产能的报道（TrendForce/SemiMedia，访问日T0）对联电等成熟代工偏利多；对中芯的映射是**本土替代订单韧性**，但若全球成熟节点价格战，中芯成熟逻辑ASP仍承压。

竞争：华虹攻特色工艺（功率/嵌入式），毛利率低于中芯但弹性大；联电/格芯是成熟代工估值锚；台积电不可直接比毛利率/PE。


### 6.1 周期位置（映射到中芯变量）
- 代理1：公司自身利用率（2024 85.6%→2025 93.5%→1Q26 93.1%）显示已处高位。  
- 代理2：华虹利用率接近满载、毛利率修复（1Q26）。  
- 代理3：联电传出涨价与成熟节点回暖（WebSearch，2026H2叙事）。  
映射：中芯2026中性假设“量增仍在、价格略升、但利用率难再台阶式上行”；上沿对应乐观，下沿对应消费电子被存储挤出需求的公司自述风险。

### 6.2 价格战触发条件
当且仅当：①大陆12英寸成熟产能集中释放；②消费电子回落；③出口管制迫使厂商全部挤在成熟节点——则ASP与利用率可能双杀。该组合是悲观情景的行业侧触发器。

### 8.1.2 卖方内部分歧
- **乐观尾部**（光大、银河等）：2028E净利可到107–109亿元，强调AI配套与涨价。

### 5.8 现金流与资产负债补充（补强财务体检）

### 9.4 情景概率的贝叶斯直觉
为何悲观给30%而非15%？因为出口管制是**厚尾风险**：一旦许可政策再下台阶，对产能与估值的冲击非线性，且难以被季度运营优化对冲。乐观25%对应“涨价完全覆盖折旧+管制稳态+稀缺溢价维持”，需要多个条件同时成立。中性45%是“高利用率平台期+折旧摩擦+倍数缓慢回归”的默认路径。

### 11.1 市值路径与现价隐含
T0市值12,308亿元若要在2028年不亏（忽略资金成本），隐含需要乐观情景附近落地，或中性利润配上显著高于本报告的倍数。用倒推：现价≈12,308亿 / 82亿净利 ≈ **150×2028E中性净利**；即使对共识93亿，也有**132×**。全球成熟代工极少长期交易在100×以上远期PE。因此“持有到期靠利润增长消化估值”的路径在数学上要求净利在数年里再翻数倍，超出产能与管制约束下的可实现区间。

## 1. 公司与商业模式拆解
**一句话结论**：价值创造链路是「型号立项→批产交付→审价结算→回款/垫资循环」，利润形成受军品定价机制约束，现金流质量长期弱于会计利润。

（技能：业务模式拆解 / china-unit-economics / 初识个股框架）

### 1.1 价值创造链路
特定用户国防需求 → 型号研制/定型 → 小批试制 → 批产交付（收入确认）→ 维修保障/改装 → 合同负债冲减与回款 → FCF → 再投资（新厂区/复材钛合金）与分红。  
经营模式为订单制直销：销售价格依军品定价采购规定确定；主要供应商需军工资质（来源：2025年报「经营模式」）。

### 1.2 收入结构（2025A）
| 分部 | 收入（亿元） | 占比 | 毛利率 |
|------|-------------|------|--------|
| 航空产品（航空制造业） | 443.78 | 99.38% | 13.74% |
| 其他 | 2.77 | 0.62% | ~6–9%（分部口径） |
| 合计 | 446.56 | 100% | 13.70% |

（来源：2025年报主营分行业/分产品；披露日约2026-03-30）

控股子公司：沈飞公司营收约427亿、净利约34.8亿；吉航公司（维修保障相关）营收约20.2亿、净利约0.53亿（兴业证券年报点评，WebSearch 2026-07-27访问）。维修仍薄，但战略上公司在推进「制造+服务」（海南维修基地、吉航增资等，券商/年报口径）。

### 1.3 主机厂特殊性
- **客户集中**：前五名客户销售额占99.42%，存在单一客户超50%（特定用户，非关联）（2025年报）。  
- **利润机制**：成本加成→目标价格+激励约束；净利率已突破传统5%红线至约7.9%，但进一步抬升受审价「反向压价」约束（定价改革文献+历史路径）。  
- **单位经济**：架次/单价涉密，**禁止编造**。用代理变量：收入、合同负债、存货、在建工程。

### 1.4 本章结论
- 商业模式是「资质壁垒下的订单制制造」，不是高FCF消费龙头。  
- 航空防务贡献几乎全部收入与利润。  
- 单位经济只能用财务代理，产量叙事不可审计。  
- 可证伪：若民品/维修收入占比持续抬升且毛利显著高于主机，则「纯主机厂」叙事需修正。

## 2. 业务与壁垒（护城河）
**一句话结论**：护城河仍宽，主因「型号垄断+资质+客户转换成本」，批产效率是加分项而非主壁垒；未来3年最可能侵蚀来自利润率不及预期与估值透支后的基本面证伪，而非同业抢型号。

（技能：护城河评估 / china-competitive-analysis）

| 维度 | 评分(1–5) | 证据 |
|------|-----------|------|
| 型号谱系与系统集成 | 5 | 公开媒体/年报口径下战斗机与舰载机主机地位；平台分工相对西飞（运轰特）、洪都（教练）、中直（直升机） |
| 客户绑定与转换成本 | 5 | 前五大客户99%+；单一大客户超50% |
| 批产工艺与交付可靠性 | 4 | 均衡生产推进；但2025上半年/2026Q1交付节奏波动显示爬坡摩擦 |
| 供应链与集团协同 | 3.5 | 关联采购占比高（前五供应商关联采购约占采购46%）；既是协同也是约束 |
| 维修保障粘性 | 3 | 吉航增长快但规模仍小；南北维修布局在建 |
| 成本与定价谈判 | 3 | 激励约束打开空间，但审价可回收降本收益 |
| 制度性约束 | 4 | 资质强化壁垒，亦限制利润率与披露透明度 |

**综合**：护城河 **宽**，属性偏「型号垄断+资质」而非「批产效率+成本」。未来3年侵蚀源排序：①利润率修复证伪；②交付换挡；③配套瓶颈；④估值透支；⑤资产注入预期落空。

**H1裁决：部分成立（壁垒宽，但是否「仍能支撑溢价」取决于利润率与现金流）** — 证据强度：高。

### 1.5 收入模式细节与「以销定产」
公司按用户采购计划与合同进度组织生产，涉及试飞、总装、部装、零件配套与器材采购全环节（2025年报）。这意味着主机厂的「产能利用率」不仅取决于自己的装配线，还取决于上游准时齐套率。2025年报与券商点评多次提到「关键器材及时配套率」改善——这是交付弹性的微观开关。买方跟踪时，除合同负债外，应同时看预付款项（向上游锁定供给）与应付账款（占用配套商资金）的联动。

民用航空产品与转包若存在，年报未单列足以改变投资结论的利润贡献；航空产品收入占比99%以上，利润贡献高度同源。因此分部预测的关键不确定项不在民品，而在防务内部的「成熟型号 vs 新型号」组合——组合不可直接观察，只能通过毛利率季度波动反推。

### 2.1 壁垒评分的同业对照说明
对西飞：运输/轰炸/特种机平台，毛利率与净利率长期低于沈飞，护城河同样来自资质，但盈利质量较弱，故沈飞「宽护城河+更强变现」成立。  
对洪都：教练机为主，利润极薄，成长故事与沈飞不在同一利润池。  
对中直：直升机主机，ROE与净利率偏低，历史重组预期扰动估值。  
对国际：LMT等护城河来自多域防务组合与全球客户，沈飞更「单域、单客户」——壁垒宽度类似「国家级」，但经济利润上限更受制度约束。


## 3. 经营战略与执行
**一句话结论**：战略优先级清晰（转代、产能、数字化、维修、军贸），执行力中上，但2026开局交付节奏验证承压。

（技能：管理层体检 / 增长质检）

- **战略**：年报强调产品转代更迭、新厂区、复材/钛合金、AOS管理、维修服务、军贸开拓。  
- **Capex**：2025在建工程38.91亿（+123%），新厂区；定增约40亿投向能力建设（年报/券商）。  
- **分红**：拟每10股派2.65元，约7.51亿（对2025归母净利派息率约21%）（2025年报）。  
- **2026验证**：Q1营收26.12亿（−55%）、净利1.65亿（−62%），但OCF +63.2亿（回款脉冲）；公司预告2026H1净利约4.75亿（约−58%），称交付以新型装备为主、产能爬坡优化中（雪球/公告口径，WebSearch）。  
- **执行力评分**：**中上**（长期净利连续增长与毛利率抬升得分；节奏波动与现金质量扣分）。  
- **治理**：航空工业集团控股；关联交易规模大但披露完整；评分 **中**（集中度与关联采购需持续盯定价公允性）。

## 5. 深度财务体检
**一句话结论**：盈利能力在主机厂中领先，但「收入—合同负债—存货—应收」三角显示垫资特征显著，财务健康评级为「观察」。

（技能：财报解读 / china-earnings-analysis / china-3-statement-model / china-variance-commentary）

### 5.2 利润率桥
毛利率 2021→2025：9.8%→13.7%（+约3.9pct），驱动可分解为：规模/均衡生产摊薄 + 结构 + 定价改革激励（定性）− 费用上升。  
2025费用：管理10.73亿（+15%）、研发10.97亿（+51%）、销售0.11亿。净利率高位横盘（7.97%→7.93%），显示费用与研发吞噬了部分毛利改善。  
**拒绝默认叙事**：「定价改革必然继续抬升净利率」——触发条件应是可验证的激励利润入账且不被审价回收。

### 5.3 合同负债—存货—收入三角（强制）
| 时点 | 合同负债 | 存货 | 应收 | 信号解读 |
|------|----------|------|------|----------|
| 2023末 | 67.1 | 116.5 | 71.2 | 预收尚可，应收可控 |
| 2024末 | 35.3 | 136.0 | 192.3 | 预收消耗+备产/交付，应收飙升 |
| 2025H1 | 75.3 | 115.1 | 186.1 | 预收回升（订单/预收款） |
| 2025Q3 | 56.5 | 129.1 | 203.7 | 预收回落，交付确认 |
| 2025末 | 44.3 | 113.3 | 298.4 | 收入确认后应收高企；OCF仍负 |
| 2026Q1 | 46.7 | 133.5 | 214.9 | 预收微升；回款使应收下降、OCF大额为正 |

（来源：Wind/iFind财务；2025年报；2026Q1报告）

**机制**：合同负债↓+收入↑ ≈ 交付确认；合同负债↑+存货↑ ≈ 备产；应收↑+OCF负 ≈ 垫资。2025是「交付确认+回款滞后」组合；2026Q1是「收入弱+回款强」脉冲，**不可线性外推全年**。

### 5.4 质量与回报
- OCF/净利润：2023–25连续为负，含金量差。  
- 前五大客户99%+；关联采购高。  
- ROE仍显著高于西飞/洪都/中直（见附录C）。  
- 净负债低（有息负债2025末约6亿 vs 货币资金97亿），资产负债表「不差钱」但营运资本占用重。

### 5.5 五大财务事实
1. 2025收入446.6亿/+4.25%，净利35.2亿/+3.65%。  
2. 毛利率创近年新高13.7%，净利率≈7.9%横盘。  
3. 应收298亿（+55%），合同负债44亿（+26%但仍远低于2022峰值叙事中的高位）。  
4. OCF三年为负；2026Q1单季转正属回款脉冲。  
5. 在建工程翻倍，产能期权真实但折旧与学习曲线将压制近端利润率。

**财务健康评级：观察**。

### 5.6 季度节奏与「不可外推」利润
2025年四个季度毛利率约12.65% / 11.99% / 10.79% / 15.30%，归母净利率约7.38% / 8.03% / 3.77% / 8.97%（兴业证券年报点评，WebSearch）。Q3利润率低谷与Q4脉冲并存，说明：  
1. 产品结构与结算节点可在单季造成巨大扰动；  
2. 任何「线性季度外推」都会系统性误判全年；  
3. 冗余利润来自集中交付与暂估差异时，不应直接资本化为永续ROIC提升。

### 5.7 股东回报与资本配置（H6）
Capex纪律：扩产导向明确（新厂区、复材、钛合金），符合主机厂战略，但抬升未来折旧。ROE仍显著高于WACC假设（8–8.5%），经济利润为正；然而FCF多年为负，ROIC若按经营资产（含巨额应收与存货）计算会被营运资本稀释。分红与再投资平衡偏「保增长」：派息率约20%出头，剩余用于产能与研发。资产注入：市场或交易「未上市航空资产期权」，本报告**不计入**中性市值；若公告则单独加期权价值。

**H6裁决：部分成立** — 证据强度：中。



**H2裁决：部分成立**（引擎仍在，但2026为换挡年）— 证据强度：高。

## 6. 行业特点与竞争格局
**一句话结论**：国内主机厂按平台分工竞争，沈飞的比较优势是战斗机/舰载机总装位势与更高ROE，而非「军费增长」。

- **采购—收入映射**：列装计划→合同/预收（合同负债）→批产→收入确认；公开可跟踪代理是合同负债与收入节奏，不是宏观军费口号。  
- **定价传导**：目标价格+激励约束使净利率可超5%，但降本收益部分归买方；沈飞净利率~8%已近主机厂舒适区上沿。  
- **竞争**：西飞（大中型）、洪都（教练，利润极薄）、中直（直升机，ROE低）；成飞等未完全同口径证券化资产需分清主体。  
- **批产期**：固定成本摊销改善毛利；转代初期往往反向。

禁止套话：本报告不将地缘叙事直接映射为买入理由。

## 补充章S1：收入确认与交付节奏的买方拆解（扩展）

2025年收入仅+4.25%，但四季度单季营收同比约+37%、归母净利约+37%（山西证券2026-04-09点评，Drive PDF）。这意味着全年「平淡」掩盖了下半年交付脉冲——主机厂季节性极强，用一季报外推全年是买方常见错误。

2026Q1收入26.12亿元（−55.23%）、归母净利1.65亿元（−61.69%），同时经营现金流净额+63.19亿元（来源：2026一季报）。财务语言翻译：「交付确认少、回款多」。存货升至133.5亿元、合同负债46.7亿元，更接近「备产蓄水」而非「需求消失」。公司随后预告2026H1归母净利约4.75亿元（约−58%），并说明上半年交付以新型装备为主、产能爬坡优化中（公开预告/雪球转引，访问日T0）。**可证伪条件**：若2026Q3–Q4收入不能出现类似2025Q4的追赶脉冲，则中性收入470亿假设需下调至悲观带（≤450亿）。

对2026–2028收入桥（中性）的机制表述：
```
2025A 446.6
+ 成熟型号稳态交付（用收入代理，不假设架次）
+ 新型号批产爬坡贡献（公开可观测为收入结构与毛利率波动）
+ 维修/改装小幅贡献
− 转代期产出效率损失与配套约束
= 2026E 470（+5%）
+ 新厂区产能释放与良率改善
= 2027E 530（+13%）
+ 稳态中速
= 2028E 575（+8%）
```
乐观情景把2027–28的产能弹性打满（680亿终点），悲观情景假设转代拖延使收入CAGR接近0–2%（470亿终点）。

## 补充章S2：利润率工作纸与「修复叙事」证伪边界

历史毛利率路径（Wind）：2021 9.76% → 2022 9.95% → 2023 10.95% → 2024 12.47% → 2025 13.70%。这是过去五年主机厂里少见的「单调改善」。净利率同步从约5%抬至约8%，与军品定价改革（目标价格+激励约束）的时间线大致吻合（浙商/东兴等历史研报，WebSearch）。

但买方必须问：改善的「边际」还剩多少？
1. **规模摊薄**：均衡生产与批产成熟仍有空间，但2025研发费用+51%显示科研交叉并行在抬升费用率。  
2. **结构效应**：新型号早期学习曲线通常压低综合毛利率——这是本报告中性毛利率略低于2025A（13.3–13.5% vs 13.7%）的核心理由。  
3. **定价/审价**：激励约束打开上沿，同时「降本被买方回收」封死暴利。把净利率中枢从7.9%外推到9%+，需要军贸或维修占比显著上升的证据，目前不足。  
4. **一次性因素**：信用减值、股权激励、政府补助需逐季剥离；2025扣非净利34.46亿，与归母35.18亿差距不大，质量尚可。

**利润率敏感度（对2028市值）**：在收入575亿、PE24×不变时，净利率每±0.5pct → 净利±2.875亿 → 市值±69亿（约±2.4元/股）。因此「市场隐含净利率8.3% vs 本报告7.6%」单独可解释约百亿市值预期差。

**H3补充裁决**：利润率弹性对「量」仍敏感，但对「率」的进一步上修不应作为默认乐观前提；三情景已显式给出收入增速×毛利率/净利率路径。

## 补充章S3：预期差交易含义与仓位含义（扩展）

## 补充章S4：同业相对溢价估算（方法A/B/C）

**方法A（水平比较，T0）**：沈飞PE(TTM)37.7 vs 西飞52.0 / 中直43.9 / 洪都335。洪都因微利失真；相对西飞沈飞「更便宜」，但西飞净利率仅2.8%、ROE5.3%，高PE含大飞机期权。相对中直，沈飞ROE与净利率全面领先，37.7 vs 43.9并不贵。

## 补充章S9：商业模式「现金循环」与关联交易定价

主机厂的现金循环不同于消费制造业：先备料（预付/应付与存货）、再总装试飞、再交付确认收入、最后按财政与用户节奏回款。2025年预付款项53.86亿（+160%）、应付账款366.4亿（+45%）、应收账款298.4亿（+55%）同时扩张，说明产业链上下游都在「加杠杆备战」。对买方而言，这提高了收入弹性，也提高了「收入高增、现金滞后」的概率——H5成立的微观基础。

关联交易方面，向关联方采购原材料、燃料、动力等2025实际约191.6亿元，2026预计约192.1亿元（兴业点评）。关联采购占比高并不自动等于「利益输送」，但意味着毛利率对集团内部转移定价与配套节奏敏感。监控方法：比对每年预计额度与实际完成度、毛利率与关联采购占比的同步变化。若毛利率下行同时关联采购溢价上升，则治理折价应加大。

## 补充章S10：护城河侵蚀路径的情景化

最可能的侵蚀不是「西飞来造舰载机」，而是：
1. **利润率侵蚀**：审价收紧+学习曲线，使市场从「净利率8%→10%」叙事退回到「7%封顶」。  
2. **交付节奏侵蚀**：转代期长达2–3年，收入CAGR降到个位数，PE中枢下移。  
3. **配套侵蚀**：航发/机载瓶颈使在制品堆积，存货周转恶化。  
4. **估值侵蚀**：军工Beta下行，即使利润达标也杀估值。  
5. **叙事侵蚀**：公众号「架次×天价」被证伪后，主题资金退出。

成飞等平台的证券化进展若改变「稀缺性溢价」，需重新评估沈飞相对溢价——目前仍属观察项，不纳入Base。

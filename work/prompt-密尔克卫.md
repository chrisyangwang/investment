## 4. 市场预期差与反共识检验（核心）

1. 从券商研报中**逐条抽取卖方一致预期的关键假设**（如分销业务增速与毛利率、仓储投产节奏与出租率、并购贡献、费用率下行、单箱/单吨盈利），列成表格：假设内容 / 出自哪家哪篇 / 隐含数值 / 我的验证结果（成立/部分成立/证伪）/ 一手证据来源。
2. 对每条假设用一手数据证伪：用年报附注、分部数据、在建工程与资本开支节奏、产能投放公告、运价与化工品价格外部数据做对照。
3. **明确点名哪些叙事站不住脚**，例如但不限于："分销业务是高粘性渠道服务" vs "低毛利贸易放大收入"、"并购即增值" vs "商誉与整合成本吞噬回报"、"轻资产平台" vs 实际资本开支强度。用数字判定。
4. 给出预期差的**方向、幅度与验证时点**：市场错在哪一变量、错多少（量化到收入/利润/估值影响）、未来哪一期财报或哪个公告会证实或证伪。
5. 同时列出**做空方（bear case）最强的三条论点**，并逐条回应。

## 5. 三情景预测与估值

- 用三表联动模型预测 **2026E/2027E/2028E**，分板块驱动（量×价×毛利率），不得只做总量外推。给出每种情景的假设表：分板块收入增速、分部毛利率、费用率、资本开支、营运资本天数、有效税率、少数股东损益占比。
- 三情景定义必须给出触发条件：乐观（化工品需求回暖 + 仓储项目按期投产满载 + 并购持续增厚）、中性、悲观（分销价差压缩 + 新增库容爬坡不及 + 应收减值与商誉减值）。
- 估值：**先论证为什么选这个方法**（考虑重资产属性、并购驱动、分部盈利质量差异），主方法建议采用 **分部估值（SOTP）+ DCF 交叉验证**，并用 EV/EBITDA、PE、PB-ROE 及海外可比（Brenntag/IMCD/DSV/Kuehne+Nagel）做锚。DCF 必须披露 WACC 拆解（无风险利率取中国国债收益率并注明日期）、永续增长率、明确给出敏感性矩阵（WACC ±1%，永续增长 ±0.5%）。
- 输出 **2028 年乐观/中性/悲观三档目标市值与对应目标价、隐含 PE/EV-EBITDA、相对当前市值的年化回报**，并据此给出明确评级（买入/增持/中性/减持）与建仓/加仓价格区间。

## 6. 写作纪律（违反即视为不合格）

- **禁止任何宏观政策套话**（"受益于政策支持""高质量发展""行业前景广阔"等一律删除）。
- 每个数字后必须标注 **来源 + 期间**，格式如 `（2025 年报，Wind 提取，2025FY）`、`（XX 证券 2026-03 研报，一致预期）`。

- 结论必须明确、可执行，不得出现"需进一步观察"作为最终结论。
- 表格优先于文字；关键论证必须落在表格或公式上。

## 7. 证伪清单 / 自检清单（写在报告末尾，逐项打勾）

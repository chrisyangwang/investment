## 三、先建底稿，再写报告（量化门槛，全部为硬性要求）

在动笔前先构建以下数据表，并在报告中以表格形式完整呈现（缺失单元格写"未获取"，不得插值、不得估算后当作事实）：

1. **分部量价表**：把收入拆到 5 个分部——速冻鱼糜制品、速冻肉制品、速冻面米制品、菜肴制品、农副产品（贸易）——给出各自 **2019—2026H1 的收入、销量（吨）、吨价（元/吨）、吨成本、毛利率、收入占比、毛利贡献占比**；并做 **量价拆分**：收入增速 = 销量增速 + 吨价增速 + 交叉项，逐年给出三者的贡献百分点。
2. **内生 vs 并表拆分**：逐年剔除新宏业、新柳伍、功夫食品、冻品先生/安井小厨、海外主体（须核实标的清单与并表起始月份）的并表贡献，给出**可比口径内生增速**。明确回答：过去三年报表增长中有多少来自并购与低毛利农副产品贸易。
3. **产能表**：各基地（厦门、无锡、泰州、辽宁、四川、河南、湖北、山东等，以年报为准）设计产能、在建产能、投产时点、实际产量、**产能利用率**，及固定资产+在建工程 / 收入的资本密集度趋势。
4. **渠道结构表**：经销 / 商超 / 特通直营 / 新零售电商的收入与增速；估算并论证 **B 端 : C 端** 收入结构及其毛利差；经销商数量、单商产出、区域分布变化。
5. **单位经济与资本回报**：ROIC（剔除商誉前后各一套）、增量资本回报 ROIIC = ΔNOPAT / Δ投入资本（滚动三年）、人均创收、吨投资额；判断**扩产是否在创造价值**。
6. **现金流质量**：经营现金流/净利润、收现比、应收账款与应收票据周转、存货周转与库龄、合同负债（预收）同比、票据贴现与供应链融资痕迹、分红率与自由现金流覆盖。

## 五、第八章：市场预期差（核心）

按以下步骤写，**不要写成观点罗列**：

1. **锚定共识**：从券商研报 PDF 中提取一致预期的**显性假设**并列表——2026/2027/2028 年收入增速、各分部增速、毛利率、净利率、目标 PE。
2. **拆解共识的隐含条件**：把每条预期翻译成可验证的业务条件（例如"菜肴制品三年 CAGR 25%"隐含每年需新增多少吨销量、多少产能、多少大单品）。
3. **逐条证伪/证实**：用第三节的一手底稿数据打分，输出表格：`共识假设 | 隐含条件 | 一手数据证据 | 判定（成立/存疑/证伪）| 我的假设 | 差异幅度`。
4. **重点审讯以下叙事**（必须逐条回应）：
   - "经营拐点已确立 / 反转加速"——用单季环比、同店式的经销商同比、吨价与毛利率的边际方向验伪，区分"基数效应"与"真实拐点"。
   - "预制菜（菜肴制品）是第二增长曲线"——看其毛利率是否在稀释整体、是否依赖低毛利贸易与并表。
   - "C 端锁鲜装打开高毛利空间"——看 C 端增速与费用投放的净效应。
   - "价格战结束、盈利修复"——看吨价与吨成本的剪刀差方向，而非管理层表述。
   - "海外/H 股带来估值重估"——量化其对利润与摊薄的实际贡献。
5. **明确结论**：哪些叙事站不住脚、市场在什么变量上系统性高估或低估、预期差何时被证实（时间与观测指标）。

## 七、第十章：估值方法与目标市值

1. **先论证方法选择**：说明为何选（或不选）DCF、分部加总 SOTP、PE/PEG、EV/EBITDA、DDM，结合公司现金流稳定性、资本开支周期、分部盈利能力差异给出理由。至少 **DCF + 可比公司 PE + SOTP** 三法交叉。
2. **DCF**：WACC 逐项列示（无风险利率取中国国债到期收益率并注明取数日、beta、ERP、债务成本、目标资本结构），永续增长率给理由，明示预测期自由现金流推导。
3. **可比公司**：三全、千味央厨、海欣、惠发、味知香、立高等，给 PE/PB/PS/EV-EBITDA、增速与 ROE 对照，说明安井应给溢价还是折价及幅度。
4. **输出**：三情景下 **2028 年目标市值区间与对应目标价**，折现回当前得到隐含回报率；给出评级（买入/增持/中性/减持）与建议买入区间、止损/证伪价位。AH 两地上市的须分别给出 A 股与 H 股口径。

## 九、交付前自检清单（逐条打勾并在附录呈现结果）

1. **数据一致性**：Wind vs 年报原文 vs 券商研报，同一指标三源比对，差异 >2% 的必须解释。
2. **口径一致性**：收入是否含并表标的？是否含低毛利农副产品贸易？增速是报表口径还是可比口径？分部毛利率是否含运费重分类？口径变更年份是否已对齐。
3. **勾稽关系**：收入 ↔ 应收账款+票据 ↔ 经营现金流 ↔ 存货 ↔ 合同负债，是否同向合理；净利润与经营现金流长期背离须给解释。
4. **分部加总**：各分部收入/毛利加总是否等于合并数（差异在抵消项内）。
5. **预测自洽**：2028 年预测销量是否被产能覆盖；预测净利率是否隐含费用率不合理下降；三情景是否互不重叠且概率加总为 1。
6. **反共识闭环**：第八章每条共识假设都有判定结论，无一遗漏。
7. **无编造**：全文抽查 10 个数字，逐一回溯到来源文件的具体页/表。

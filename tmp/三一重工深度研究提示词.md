## 2. 研究流程（严格按序，允许并行取数但禁止跳步下结论）

### Phase A — 资料盘点（0.5–1 天工作量等价）

1. Drive 三目录文件清单（文件名、日期、页数/大小、摘要标签）。  
2. Wind `financial_docs` 拉取最近 3 年年报 + 最近 8 个季度报告索引。  
3. 建立「数据字典」：字段 → 来源 → 最新时点 → 置信度（高/中/低）。

### Phase B — 业务与竞争事实层

1. 产品矩阵：挖掘机械、混凝土机械、起重机械、桩工机械、路面机械、港口机械、新能源装备/其他。  
2. 收入与毛利拆分（国内 vs 海外；主机 vs 后市场/配件/服务——若披露不足，用逻辑估计并标注）。  
3. 渠道：直销/经销、融资租赁渗透、信用销售风险。  
4. 产能与利用率、全球化制造布局（中国/印度/美国/欧洲/印尼等——以公司披露为准）。  
5. 份额：挖机国内份额、出口份额、起重机/泵车等细分。

### Phase C — 财务体检与同业比选

1. 利润表、资产负债表、现金流量表三表勾稽。  
2. 营运资本周期、应收质量、存货结构（产成品 vs 原材料）、减值与或有负债。  
3. ROIC / ROE / 自由现金流转化。  
4. 与徐工、中联、柳工、CAT 的倍数与质量对比。

### Phase D — 周期定位与预期差

1. 挖机销量月度、出口金额、开工小时、经销商库存（能找到的最高频）。  
2. 一致预期（Wind/研报）vs 你的基准情景。  
3. 市场定价隐含的 2026–2028 增长与利润率假设反推。

### Phase E — 三情景建模与估值

1. 自下而上：销量 × ASP × 结构 × 毛利率 × 费用率 × 税率 × 少数股东。  
2. 选定主估值方法 + 1–2 个交叉验证。  
3. 给出 T0（当前）合理市值带 + **2028 年末**三情景市值。

### Phase F — 成稿、质检、上传

1. 按第 4 节结构写 `三一重工深度研究报告Grok.md`。  
2. 跑第 8 节 QC 门禁。  
3. 上传 Drive：`Investment/公司分析/三一重工/研究报告/研究报告Grok/三一重工深度研究报告Grok.md`（目录不存在则新建）。

## 3. 核心分析框架（提示词心脏）

### 3.1 业务与壁垒（必须定量）

回答这些问题，禁止用形容词代替证据：

1. **客户转换成本**：工程机械主机的品牌、配件、服务网络、再制造、融资方案如何锁客？用配件收入占比、服务网点数量、客户复购或保有量数据支撑。  
2. **规模与成本**：吨钢耗、液压件自制率/外购结构、规模采购、智能制造（灯塔工厂）对单台成本的可量化影响。  
3. **技术壁垒**：电动挖机、液压系统、控制算法、大型起重、港机等，专利与产品代差是否构成定价权？  
4. **渠道与全球化壁垒**：海外经销商密度、本地化生产、备件中心、品牌认知 vs CAT/Komatsu/日立/Volvo。  
5. **金融与风险控制壁垒**：融资租赁、信用销售的风控能力是护城河还是风险源？  
6. **护城河评分**：对「无形资产 / 转换成本 / 网络效应 / 成本优势 / 有效规模」五维各打 1–5 分，总分与「三年后可能下降的维度」。

### 3.2 经营战略与执行

必须区分「战略叙事」与「执行结果」：

1. **战略主线**（以公司原话+你的转译）：国际化、电动化、数字化、后市场、高端化等——每条主线对应 KPI。  
2. **执行仪表盘**（近 3–5 年）：海外收入占比、电动产品销量/收入、研发费用率、人均产出、存货周转、经营现金流/净利润。  
3. **资本配置**：分红、回购、扩产、并购、金融业务扩张——是否提升 ROIC。  
4. **管理层质量**：股权激励、质押、关联交易、重大承诺兑现率；梁稳根/向文波等关键人事信息只写与治理/激励相关的事实。  
5. **战略一致性检验**：若海外高增但应收恶化，则「国际化」评分下调并解释。

### 3.3 深度财务体检（买方级别）

至少覆盖：

**A. 成长与盈利**

- 2019–2025（或最近完整年度）收入、毛利、营业利润、归母净利、扣非净利 CAGR；  
- 分产品/分地区毛利率走势；  
- 费用率拆解：销售（含服务与渠道）、管理、研发、财务；  
- 利润率中枢：周期高点/低点/当前位置。

**B. 资产负债表与质量**

- 货币资金、有息负债、净现金/净负债；  
- 应收账款 + 应收票据 + 合同资产 vs 收入；账龄与坏账准备；  
- 存货结构与跌价准备；  
- 长期股权投资、商誉、金融资产；

**C. 现金流**

- CFO、CFI、CFF；  
- FCF = CFO − 资本开支（定义写清）；  
- 收现比、净现比；  
- 自由现金流对分红的覆盖。

**D. 回报率**

- ROE 杜邦拆解；  
- ROIC（投入资本定义写清）；  
- 与徐工/中联对比。

**E. 会计与一次性项目**

- 政府补助、资产处置、汇兑、减值、股权激励费用；

### 3.4 行业特点（工程机械专用，拒绝空泛）

用「机制」描述行业，而不是形容词：

1. **强周期 + 更新需求 + 出口缓冲**：国内挖机销量与地产/基建/矿业/农村的关系；更新周期（保有量机龄）。  
2. **寡头竞争**：CR3/CR5 变化；价格战触发条件（库存、利用率、新进入者）。  
3. **主机赚钱 vs 后市场赚钱**：海外成熟市场后市场利润池；中国后市场是否仍薄。  
4. **供应链**：发动机、液压件、电控、电池/电驱（电动化）；国产替代进度与议价。  
5. **政策与标准的真实传导路径**：排放标准切换如何影响提前抢购与随后透支（用历史 国三/国四 证据）。  
6. **金融条件**：按揭/融资租赁利率与首付如何放大周期。

### 3.5 发展趋势与公司位势（2026–2028）

按主题写，每主题必须有「行业 β」与「三一 α」两列：

1. 国内周期位置：复苏 / 磨底 / 二次下行 —— 用高频数据判定，给出概率。  
2. 出口：区域结构（「一带一路」需落到东南亚/中东/非州/拉美/欧美具体份额变化）、贸易摩擦与关税、本地化生产对冲。  
3. 电动化与智能化：渗透率曲线、ASP、毛利率影响、对传统经销商的冲击。

3. 若「否（仍处谷底或高峰）」：主方法用 **通过周期平均利润 × 目标 PE**，避免把峰值/谷值 EPS 直接乘历史峰值 PE。  
4. SOP：若后市场与金融利润占比提升且披露改善，可提高 SOP 权重。  
5. 最终对外表达必须是：**主方法结论为「官方」建议市值；交叉验证列出偏差。**

给出 2028 市值时，同时写明：

- 目标 PE 或 EV/EBITDA 的取值理由（对照历史分位与 CAT 折价）；  
- 股本假设（回购/股权激励稀释）；  
- 是否含永续增长争论（若用 DCF）。

## 4. 各章研究任务书（可执行细节）

### 4.1 公司与商业模式拆解
**技能**：业务模式拆解 skill、初识个股 skill、china-unit-economics（如适用）  
**输出**：
- 价值创造链路：Biotech/Big Pharma 客户需求 → 发现/开发/生产服务 → 定价（FFS / FTE / 里程碑）→ 产能与科学家密度 → 收入确认。  
- 收入模式拆解：项目制 vs 长约；发现端 vs 开发端 vs 商业化生产的利润率梯度。  
- 「CRDMO」一体化的交叉销售证据：客户数、wallet share、后期转化率（能挖尽挖）。  
- 单位经济模板（能估则估）：单项目贡献、单公斤商业化生产毛利、TIDES 产能利用率、人均产值。  

**禁区**：复述官网口号而无财务映射。

### 4.2 业务与壁垒
**技能**：护城河评估 skill、china-competitive-analysis  
**按维度打分（1–5）并给证据**：
1. 规模与产能网络（中国+海外）  
2. 技术平台广度（小分子、TIDES、测试、生物学、ATU）  
3. 客户转换成本与合规/质量体系（FDA/NMPA/EMA 相关检查与交付记录）  
4. 人才密度与交付可靠性  
5. 数据/化合物库/历史项目沉淀（若有）  
6. 成本优势 vs 地缘政治折价对冲后的净优势  

输出 **护城河综合结论**：宽/窄/正在变窄或变宽，以及未来 3 年最可能的侵蚀来源（客户自制、同行扩产、监管、地缘）。

### 4.3 经营战略与执行
**技能**：管理层体检 skill、增长质检 skill  
**必须覆盖**：
- 战略优先级：化学强化、TIDES、海外产能、ATU、股东回报。

## 20. 估值计算的最低展示公式

### 20.1 远期 PE 法（示例）
```
目标市值_2028 = 2028E 归母净利 × 目标 PE
目标 PE = 同业中位数 × 公司质量溢价/折价 × 地缘折价因子 × 增长溢价因子
隐含 A股价格 = 目标市值 / 总股本（注明是否全稀释）
```

### 20.2 EV/EBITDA 法
```
企业价值 = 2028E EBITDA × 目标 EV/EBITDA
股权价值 = EV - 净债务 + 其它调整（长期投资、少数股东等）
```

### 20.3 FCFF-DCF
```
FCFF = EBIT(1-t) + Dep - Capex - ΔNWC
EV = Σ FCFF_t/(1+WACC)^t + TV/(1+WACC)^n
TV = FCFF_{n+1}/(WACC-g) 或 EBITDA_n × 退出倍数
```

### 20.4 必须提交的敏感度热力图（文字表即可）
行：WACC 或 PE；列：2028 净利或永续 g；中心格为中性。

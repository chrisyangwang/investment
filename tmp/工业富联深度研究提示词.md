## 四、报告正文必须覆盖的研究模块

报告必须按以下结构组织（可增小节，不可删主模块）。每一模块结尾给出 **本节结论（1–3 条，必须可证伪）**。

### 模块 A｜投资摘要（先写结论）
- 一句话投资判断：买入/增持观望/中性/回避（选一，并给 12 个月视角）
- 核心矛盾 3 条（不是亮点罗列）
- 预期差分值：市场定价 vs 你的基本面判断（高估/合理/低估 + 幅度区间）
- 关键 2028 中性情景目标市值与隐含回报（相对当前市值）
- 最可能证伪你论点的 2 个观察点

### 模块 B｜业务与壁垒
必须回答：
1. 收入与利润的真实驱动拆分：通信网络与云服务设备 / 精密工具与工业机器人 / 其他，如何与“AI 服务器、传统服务器、网络设备、消费电子相关制造”等市场叙事对齐或偏离
2. 价值创造环节：ODM/OEM、整机、主板、机柜、液冷、零部件垂直整合，各自毛利率与资本密度差异
3. 护城河类型排序（规模制造、良率与交付、客户认证、垂直整合、工程能力、成本曲线、地缘产能布局等），每条给证据强度：强/中/弱
4. 客户集中度与议价权：若公开数据不足，用逻辑上下界说明，禁止编造具体客户份额
5. 可复制性：后来者 3–5 年能否追上关键产能与认证；卡点在资本、人才、供应链还是客户关系
6. 与鸿海集团的协同与利益输送/关联交易风险边界（用披露数据说话）

拒绝：空泛的“智能制造龙头”“平台化优势”而无数据支撑。

### 模块 C｜经营战略与执行
必须回答：
1. 公司过去 3–5 年战略主线演变（云/AI 算力 vs 传统业务）
2. 资本开支、产能、研发费用率、人员与组织调整是否匹配战略
3. 管理层激励、股权结构稳定性、关键人事变化（有则分析，无则注明未见）
4. 指引 vs 实际：最近 8 个季度或最近 3 年，超预期/低于预期的次数与原因归类
5. 执行评分：战略清晰度、资源配置效率、兑现能力（各 1–5 分 + 理由）

### 模块 D｜深度财务体检
以最新年报/半年报/季报为主，构建至少 3–5 年趋势：
1. 增长：收入、毛利、经营利润、归母净利润、扣非、经营现金流（OCF）、自由现金流（FCF）
2. 盈利质量：毛利率/净利率拆解；AI 相关业务混入后的结构性毛利变化；费用率；资产减值与信用减值
3. 资产负债表：应收账款与存货周转、合同负债/预收款、资本开支强度、净现金/净负债、商誉与长期资产
4. ROIC / ROE 杜邦与投入资本回报是否被“收入暴增”掩盖
5. 现金流转换：净利润 → OCF → FCF 的漏损点
6. 分红分析：同比/环比异常科目必须解释（`china-variance-commentary` 思维）
7. 会计与披露质量：收入确认、关联交易、分部披露是否足够支撑业务结论

输出一张“财务健康度评分卡”（流动性、杠杆、盈利质量、现金流、增长可持续性）。

### 模块 E｜行业特点、发展趋势与公司位势
必须回答：
1. 行业本质：是否强周期、资本开支驱动、客户集中、技术迭代速度、库存牛鞭效应
2. AI 服务器产业链位置：上游芯片/PCB/光模块/电源/散热 → 中游整机 ODM → 下游 CSP；工业富联卡在哪一层、赚哪一层的钱
3. 需求：云厂商 Capex 节奏、柜式功率密度提升、液冷渗透对 ASP/毛利/交付周期的影响（用可引用数据或合理假设区间）
4. 供给与竞争：台系 EMS/ODM、内地服务器厂商、品牌商自研自制的替代威胁
5. 公司位势：份额、技术代际（如对新平台服务器的导入节奏）、产能弹性、地缘产能（中国大陆/海外）对订单获取的影响
6. 未来 3 年行业量价框架：出货量、ASP、附加服务（液冷/整柜）的弹性来源

拒绝：用“数字经济”“新质生产力”替代产业链推演。

- 收入占比与利润贡献（能拆则拆；不能拆则说明披露限制并给估计区间与依据）
- 增长驱动与生命周期阶段
- 竞争格局与公司相对位置
- 未来 3 年关键经营变量（量、价、毛利率、资本开支）
- 对该模块的独立判断：战略加仓 / 维持 / 收缩观察

至少覆盖：AI/云服务器相关、传统通信网络设备相关、精密结构件/工控与机器人相关（按公司实际披露口径调整命名）。

### 模块 G｜市场预期差（核心章节，必须加长）
本模块是全文核心，要求论证密度最高。必须包含：
1. **一致预期画像**：卖方盈利预测中枢（来自券商研报 PDF + Wind/iFind 一致预期）、隐含增速、隐含估值（PE/PS/EV/EBITDA）
2. **股价已定价内容**：用近期涨跌、估值分位、基金持仓变化、新闻情绪，推断市场交易的主叙事
3. **预期差清单（至少 5 条）**，每条按统一模板：
   - 市场共识是什么
   - 你的不同判断是什么
   - 证据与逻辑链
   - 若你对、对 2026–2028 利润/估值的量化影响
   - 跟踪指标与时间点
4. **多空论证**：多头最强 3 条 vs 空头最强 3 条，并给出净评估（哪边证据更硬）
5. **预期差方向结论**：正预期差 / 负预期差 / 双向不确定，并给出置信度（高/中/低）
6. 对比雪球/公众号/海外观点中的“共识幻觉”，指出哪些是二手传播而非一手数据

### 模块 H｜至 2028 年三情景业绩预测与市值估值
必须建立 **乐观 / 中性 / 悲观** 三情景，预测期覆盖至 **2028 年**（至少给出 2026、2027、2028 三年关键表）。

每个情景必须明确假设（禁止只给结果不给假设）：
- AI 服务器出货量/收入增速（或相关业务收入增速）
- 非 AI / 传统业务增速
- 综合毛利率路径
- 费用率与净利率路径
- 有效税率、少数股东损益处理方式
- Capex、营运资本、FCF
- 份额与竞争假设差异（三情景必须在关键变量上可区分）

每个情景输出：
- 营业收入、毛利、EBIT/营业利润、归母净利润、EPS
- OCF、FCF（尽量给出）
- 对应情景下你认为合理的估值方法与倍数或折现假设
- **2028 年目标市值区间**（给出中枢 + 上下界）
- 相对当前市值的隐含复合回报（CAGR）

**估值方法选择（必须单独立论）**：

## 五、写作与论证纪律

1. **拒绝宏观政策套话**：不得用大段产业政策、规划文件复述代替公司基本面；政策若提及，只能作为单一外生变量并量化影响边界
2. **数据必须引用最新来源**：优先最新定期报告与最近交易日行情；旧数据需注明日期
3. **逻辑推演优先**：每个判断写清“因为 A（数据）→ 所以 B（机制）→ 因此 C（对利润/估值影响）”
4. **结论必须明确**：禁止“整体看好但仍需观察”作为最终结论；若信息不足，明确写“信息不足，暂给中性，缺口是……”
5. **不编造**：无披露的客户份额、未公开订单金额、未证实的液冷渗透率等，只能给区间假设并标注为假设
6. **矛盾处理**：年报 vs 研报 vs 新闻冲突时，以法定披露为准，并解释卖方可能偏差
7. **数字可稽核**：关键表格中的合计、同比、利润率计算必须自洽
8. **篇幅建议**：正文建议 8000–20000 字等价信息量；预期差与三情景估值不得短于业务介绍

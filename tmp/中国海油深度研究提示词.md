### 0.2 研究必须回答的十个核心问题（H1–H10）
报告全文必须围绕并可回指以下假说；每条假说最终给出 **成立 / 部分成立 / 不成立** + 证据强度（高/中/低）：

1. **H1 产量与储量引擎是否可持续**：2026–2028 净产量 CAGR、储量接替率（RRR）、1P/2P 储量寿命是否支持公司「稳产增产」叙事？增量主要来自中国海域还是海外项目（圭亚那、巴西、加拿大等）？
2. **H2 全成本与油价安全垫**：桶油全部成本（opex + DD&A + 弃置分摊等口径需写清）相对 Brent/公司实现油价的安全垫有多厚？成本曲线位势相对「三桶油」与国际 Majors 如何？
3. **H3 油价情景敏感性**：在 Brent 悲观/中性/乐观路径下，2026–2028 归母净利与 FCF 弹性分别是多少？市场一致预期隐含的油价假设是什么？
4. **H4 天然气与结构升级**：天然气产量占比、气价机制（中国海气定价 vs 国际 LNG 挂钩）、气业务对利润波动的平滑或放大作用如何？
5. **H5 Capex 纪律与资本回报**：资本开支指引 vs 实际、开发井/勘探井结构、增量项目 IRR/回收期（能量化则量化）；ROIC 是否高于 WACC？
6. **H6 分红与股东回报可持续性**：分红率、特别分红、回购（若有）与油价/FCF 的挂钩规则；高分红是否透支再投资？
7. **H7 同业相对优势**：相对中国石油、中国石化、壳牌、埃克森美孚、雪佛龙等，中国海油的护城河是「海上低成本 + 储量质量 + 产量增长」还是「油价 Beta」？优势是否被侵蚀？
8. **H8 市场预期差核心**：一致预期（Wind/券商）对 2026–2028 产量、油价、利润、分红的隐含假设，与你的基本面推演差距在哪里？差在量（产量）、价（油/气价）、成本还是估值倍数/风险折价？
9. **H9 估值方法选择**：当前阶段最合适的主估值方法是什么（远期 PE / EV-EBITDA / P/NAV / 油价情景 DCF / 分红折现）？为何不是其它？
10. **H10 2028 市值锚**：在乐观/中性/悲观三情景下，2028 年末合理市值区间与对应 A/H 隐含价格路径是什么？当前价格隐含了哪一档情景（油价×产量×倍数的组合）？

### 0.3 写作纪律（硬性）
- **拒绝**：「能源安全」「国资改革红利」「双碳长期利好」「一带一路」等无公司特异信息的宏观套话。政策只允许在能映射到 **产量配额、气价机制、税费、弃置成本、海外项目审批** 等可量化变量时出现，且必须写出财务传导路径。
- **必须**：每个关键结论附「可证伪条件」；数字必须带来源（Wind / iFind / 年报页码或 PDF 文件名 / 券商研报标题+日期 / WebSearch URL+访问日）。
- **多用逻辑推演**：因果链写成「油价/产量/成本假设 → 机制 → 财务结果 → 估值含义」；少用形容词堆砌。
- **结论明确**：每章末尾给 3–5 条 bullet 结论；全文末给明确的投资立场（低估/合理/高估）与仓位含义（观察/标配/超配/回避），但不得写成交易指令保证。
- **时间锚**：研究基准日记为 **T0 = 执行当日**；预测窗口为 **2026、2027、2028** 三个财年；「三年后」统一指向 **2028 年末**。
- **币种与单位**：收入/利润以人民币为主；产量用 **BOE（桶油当量）** 与 **桶/日**；油价用 **Brent USD/bbl** 并给出 USD/CNY 假设；涉及 H 股估值时同步港币口径；市值同时给 A 股口径与集团股权价值口径，并说明 A/H 是否同权全流通口径。
- **油价诚实原则**：不得把「油价上涨」当作默认乐观前提而不写触发概率；三情景必须显式给出 Brent（及公司实现油价折扣/升水）路径。

5. **分红可持续性**：高分红是否依赖高油价？油价跌至某阈值时分红率/绝对分红如何调整？  
6. **A/H 溢价折价**：流动性、南向/互联互通、指数纳入、外资约束如何解释价差？  
7. **「纯上游」估值溢价是否合理**：相对中石油/中石化，海油应有多少 PE/EV-EBITDA 溢价？历史分位与当前分位。  
8. **双碳与天然气转型**：资本开支中新能源/碳中和相关占比（若披露）是否实质改变主业回报？禁止空谈双碳。

## 20. 估值计算的最低展示公式

### 20.1 远期 PE 法
```
目标市值_2028 = 2028E 归母净利 × 目标 PE
目标 PE = 三桶油/Majors 中位数 × 纯度溢价 × 增长溢价 × 油价周期位置折价/溢价
隐含 A股价格 = 目标市值 / 总股本（A+H，注明口径）
隐含 H股价格 = 按同一股权价值或独立折溢价假设（写清）
```

### 20.2 EV/EBITDA 法
```
企业价值 = 2028E EBITDA × 目标 EV/EBITDA
股权价值 = EV - 净债务 + 其它调整（长期股权、少数股东、弃置义务净额等需说明）
```

### 20.3 油价情景 FCFF-DCF
```
FCFF = EBIT(1-t) + Dep - Capex - ΔNWC
EV = Σ FCFF_t/(1+WACC)^t + TV/(1+WACC)^n
TV = FCFF_{n+1}/(WACC-g) 或 EBITDA_n × 退出倍数
必须附加：Brent 长期假设表
```

### 20.4 P/NAV 或 EV/2P（若使用）
```
NAV ≈ Σ (储量类别 × 单桶净值) - 净债 ± 其它
单桶净值对长期油价极度敏感 → 必须给油价敏感度；否则降为参考
```

### 20.5 必须提交的敏感度热力图（文字表即可）
行：Brent 或目标 PE；列：2028 产量或净利；中心格为中性。另附成本 ±USD/boe 一维敏感度。

## 二、CIO 审讯引擎挤水分（四维 Stress Test）

### ① Fad Risk：Labubu 是加强版 Molly，不是 Hello Kitty

- **事实**：THE MONSTERS 2025 收入 141.6 亿（占比 38.1%），是首个百亿级 IP；Top5 IP 合计约 71%。Molly 占比从 2017 年 89.4% → 2025 年 7.8%（绝对收入仍增至 29 亿）——**占比坍塌、绝对收入长尾**是潮玩 IP 的标准曲线。
- **2026 拐点信号已现**：美国信用卡消费同比 −40%；Labubu 新品二手溢价崩塌/破发；德银维持「沽售」；管理层指引 2026 ≥20%（远低于 2025 的 185%）引发财报日股价一度大跌超 20%。
- **路径定性**：Labubu 走的是「社媒病毒 → 时尚爆款」路径（类比 Supreme/KAWS），不是万代「动画→玩具」或 Sanrio「50 年角色授权」。爆发更快，衰减也可能更快。
- **裁决**：2028 Labubu/Monsters **绝对收入平台化至 90–110 亿**（占比从 38% → **18–22%**），不给 WorkBuddy「长红」也不给 Deepseek「崩至 45 亿」的极端。增长必须来自其他 IP 接力；若接力失败，整体增速断崖。

### ② 海外 DTC 高毛利——「增收增利」已验证，但净利率不可线性外推

- **真实红利**：2025 海外 162.7 亿(+292%)，海外分部业绩 80 亿 vs 中国 104.5 亿——海外已接近中国利润贡献的 77%。海外毛利率显著高于国内（公司口径海外溢价清晰）。
- **成本抽水**：运输物流费用 +280%；美洲线上占比 64%（病毒流量依赖）；海外使用权资产 27.9 亿、租赁负债 22.8 亿——刚性租金/人工/合规成本随开店上升。
- **增速着陆**：2026Q1 海外增速从 300–900% 骤降至亚太 +25–30%、美洲 +55–60%、欧洲 +60–65%。从爆发期进入着陆期。
- **裁决**：2028 海外占比 Base **50%**（Bull 55%、Bear 42%）；海外分部净利率从爆发期高位回归 **22–26%**（不给「海外毛利率 81% → 净利率永续高于国内」的线性外推）。美国门店扩至 100+ 是 Bull 触发条件，不是 Base 默认。

### ③ 毛绒 Mix Shift——阶段性抬毛利，也可能阶段性砸毛利

- 2025 毛绒 187.1 亿（+561%，占比 50.4%）首次超手办，是推升综合毛利率至 72.1% 的核心结构因素（零钢模 CAPEX、补货快、社交属性强）。
- **但毛绒与 Labubu 高度重叠**（估计 Labubu 相关占毛绒 >60%）。若 Labubu 衰退，毛绒可能同步承压——不是「品类升级永续」，而是「爆款载体切换」。
- 毛绒供应链壁垒、防伪难度低于工艺手办，同质化与价格战风险更高（TOP TOY/名创价格带重叠）。
- **裁决**：2028 综合毛利率 Base **66%**（Bull 69%、Bear 60%），从 72.1% 峰值回落——不给 WorkBuddy/Gemini 的 70–73.5% 永续高位。

### ④ 存货堰塞湖——54.7 亿是最大资产负债表雷

- 存货 15.2 → 54.7 亿（+259%），周转天数 102 → 123 天，增速远超收入。管理层称「全球开店备货 + 海外物流周期」，但潮玩生命周期短，IP 过气 = 库存贬值。
- 2026 年 618 已现打折/福袋清库存信号。悲观情景计入 **存货减值 8–15 亿**。
- FCF/净利约 0.76×（存货占用营运资本），质量仍好于多数消费股，但已从 2024 年 1.4× 回落。
- **裁决**：Base 假设 2026–27 存货周转改善至 ~110 天；Bear 计入大额减值直接冲击净利。

- 当前 12–14× 已反映增速换挡，但若 2026 净利负增长，动态 PE 会被动抬升——「看起来便宜」可能是价值陷阱（Deepseek 方向正确）。
- **裁决**：2028 Base PE **15×**（介于名创零售与万代 IP 之间，给 DTC + 自有 IP 矩阵合理溢价，砍掉 20–30×）；Bull 18×、Bear 10×。

### 2. 预期差核心胜负手（Not Priced-in）

**正向（潜在绝杀买点）**：
- **非 Labubu IP 矩阵的「次顶流」接力**：若刨去 THE MONSTERS，2025 收入仍 +130%；星星人 +1,602%、CRYBABY/HIRONO 高速成长。市场过度聚焦「有没有下一个 Labubu」，低估「5–6 个年入 20–40 亿的次顶流」即可支撑 400–500 亿收入底盘。
- **Labubu 大电影（索尼/保罗·金，2028）**：内容化是延长 IP 寿命的正确路径（向万代/Sanrio 靠拢），当前几乎零定价。
- **股份回购对 EPS 的被动增厚**：2026 年已耗资约 14 亿港元回购注销，卖方模型未充分计入 5–8% EPS 增厚。

**负向（市场未充分定价）**：
- **存货 54.7 亿堰塞湖**：若 Labubu/毛绒滞销，减值 8–15 亿可直接冲击个位数净利率。
- **美洲线上流量消退**：线上占美洲 64%，社媒算法迁移 → 线下承接能力未充分验证。
- **「14× 便宜」的静态陷阱**：若 2026 净利下滑，动态 PE 被动升至 16×+，在负增长年份并不便宜。

### 3. 清仓红线（Trigger Point，触发即无条件强制清仓）

1. **Labubu 硬崩盘**：THE MONSTERS 季度收入同比连续两季 <−40%，且无新 IP 补位 → 收入结构崩塌。
2. **存货爆雷**：单季存货跌价准备 >8 亿，或存货周转天数突破 150 天。
3. **海外同店崩塌**：美洲/亚太同店连续两季 <−15%，叠加海外收入占比仍 >45% → 负向经营杠杆。
4. **监管黑天鹅**：欧美对盲盒/概率抽选出台实质性禁令或类博彩监管 → 高 ASP 直营模型重创。
5. **核心设计师/版权诉讼**：龙家升等头部创作者突发版权纠纷或单飞 → 头部 IP 资产权属动摇。

## 五、结论

泡泡玛特用 Labubu 证明了「无影视内容」也能打出全球百亿级潮玩 IP，2025 年财务质量（毛利率 72%、净利率 35%、FCF ~97 亿）在全球潮玩罕见。但 38% 收入集中于单一 IP 家族、存货 +259%、海外增速断崖、管理层主动指引换挡——说明 2025 是极端年份而非新常态。

审定中性合理市值 ~2,390 亿港元（+19%）、概率加权 +9%。**对中性情景温和正期望，对悲观情景保护不足。**

**纪律建议：标配/小幅低配（3–5%），不追高。买入区 ≤140 港元；减仓区 ≥220 港元且基本面未超预期。死盯三个变量：① Labubu 占比与二手溢价、② 存货周转天数、③ 美洲同店/信用卡消费。Labubu 大电影预告与非 Labubu Top IP 合计增速是切换至 Bull 的硬催化剂。**

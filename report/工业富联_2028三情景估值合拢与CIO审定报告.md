## 一、CIO 审讯引擎挤水分（三维 Stress Test + 估值坐标）

### ① AI 机柜「高营收、低毛利」脱水——净利率 5% 是刚性天花板，不是起点

- **铁证**：一台 ~$250 万的 GB300 NVL72 整机柜，GPU+HBM+网络外购 BOM 占 **70–90%**，工业富联 ODM 费约 **~3%**（Opus 口径 ~$7 万/台）；云计算分部 GM 仅 **5.73%** 且 2025 逆势下滑——「整机柜 ASP 提升 3–5 倍」提升的是**营收**，不是**毛利率**。
- **两头受挤**：上游英伟达拿走绝大部分附加值；下游 CSP 集中度（前五大客户 62%+）意味着年度杀价刚性。Consign 模式普及还会让名义营收**缩水 10–20%**（净利影响有限但 PS/营收叙事作废）。
- **裁决**：Base 综合毛利率 **7.1%**、净利率 **4.3%**（承认规模摊薄与结构改善，拒绝卖方 7.6–8.3% GM / 4.6–5% NM 的线性上修）；Bull 净利率 **4.7%**（自研液冷+交换机利润占比冲 25–30% 临界点）；Bear **3.5%**（杀价+海外爬坡+存货跌价）。**扣非净利率破 5% 在任何情景都不作为主假设。**

### ② 海外 CAPEX 折旧与营运资金——OCF/净利比是真伪利润的照妖镜

- **前科**：2025 净利 353 亿但 OCF 仅 **52 亿**、FCF **−120 亿**、存货暴增 77%——AI 备货吞噬现金是结构性的，不是单季扰动。2026Q1 OCF 回升 250 亿是正信号，需连续验证。
- **海外重击路径**：墨西哥/越南/印度建厂转固 → 折旧抬升 + 爬坡良率损失 + 跨国管理费 → Bear 情景净利率被侵蚀 0.3–0.5pp；应收/存货垫资拉长则直接打击 ROIC 与分红能力。
- **裁决**：Base 要求 **OCF/净利 ≥1.0×** 作为估值前提（GPT 阈值框架采纳）；若 2026H2 OCF/净利再度跌破 0.8 或存货增速超收入 10pp，PE 锚自动降档至 13–14×。

### ③ 传统分部周期钝化 vs 交换机对冲

- 通用服务器/消费电子被 AI 挤压，增长归零是 Base 默认；**真正的利润接棒者是网络通信**（GM 9.28%，800G/1.6T/CPO 若 2026–28 CAGR 35–45%，每多 500 亿高毛利收入 ≈ +25 亿净利）。
- **裁决**：Base 网络收入 2,979 → **4,600 亿**（GPT 中性采纳）；工业互联网（6.9 亿收入）**从估值叙事中除名**——六年耕耘仍 <0.1% 收入，不配任何平台溢价。

### ④ 估值坐标——EMS 地板 + 份额/自研溢价，拒绝 AI 平台 20×+

| 对标 | Forward PE | 启示 |
| :--- | :--- | :--- |
| 鸿海（母公司） | ~11× | 同基因血缘地板 |
| 广达 / 纬创 | ~15–18× / ~11–12× | AI ODM 直接对标带 |
| Supermicro | ~13–15× | 品牌+ODM 混合 |
| 立讯精密 | ~15–18× | A 股精密制造 |
| 全球 EMS 中位 | **12–13×** | 商业本质地板 |

- **审判**：2028 时点 AI Capex 步入高基数成熟期，增速从 +77% 降至 +15% 上下——「成长溢价」自然衰减。A 股流动性 + 全球第一份额 + 自研零组件斜率，合计值得在 EMS 中枢上**加 2–4×**，即 **Base 15×**；只有自研模组+网络利润占比破 30% 临界点（当前 <20%）才解锁 18×+。
- **明确否决**：Gemini Base **20×**；Claude/GPT Bull **20–23×** 作为常态；WorkBuddy Bear **17.8×**（悲观情景 PE 不压缩是自欺）；以及一切用「隐含 2028 PE 仅 11× 好便宜」的循环论证——低前瞻 PE 是市场对净利兑现度打折的定价，不是白送的期权。

### 2. 市场预期差核心提炼（Consensus Gap）

**正向（尚未完全定价的绝杀买点）**：
- **自研液冷全套零组件 + 网络设备的利润结构切换**：液冷冷板/快接头/CDU（GM >30%）、800G/1.6T/CPO 交换机（GM 12–15%）、自研机壳（GM 22–25%）——自给率每 +10pp 撬动综合净利率 +0.3–0.4pp（万亿营收基数 ≈ 数十亿净利）。**若 2028 前自研+网络利润占比破 ~30%，PE 框架从「组装厂 12–15×」切换到「系统平台 18×+」，EPS 与 PE 双升**——这是六份研报中唯一被 Grok/Opus 识别、当前市场几乎零定价的非对称支点。
- **GB300 Compute Tray 独家位**：SXM 基板是 ODM 链中技术含量最高环节（GM 8–10%），份额粘性强于「纯组装」认知。
- **Consign 普及反而改善营运资本**：名义营收缩水但存货/垫资同步下降，OCF 质量上台阶——市场只看营收减速表象。

**负向（市场仍在低估）**：
- **2027–2028 Capex 高基数失速**：+15% 以下增速叠加 PE de-rating，「赚 EPS 不赚股价」的价值陷阱是 Base 而非尾部。
- **Rubin 世代份额分流**：英伟达主动扶植广达/纬创二供，份额跌破 35% 将同时打击利润与估值框架。
- **母公司利益输送暗门**：鸿海将优质订单留存 A 股体外的治理折价，永远值 1–2× PE。

### 3. 投资逻辑证伪临界点（Trigger Point）——无条件强制清仓

1. **地缘强制分单**：海外核心 CSP 因地缘政策被强制要求将整机柜订单大幅（>30%）分流至非中资背景厂商，且墨西哥/越南产能无法承接豁免——份额逻辑一次性崩塌。
2. **芯片断供休克**：GPU/HBM 供应链突发断供（管制升级或产能事故）导致全行业 AI 服务器生产休克超过两个季度，在手订单无法交付、存货跌价与客户索赔双杀。
3. **现金流证伪**：连续两个财年 OCF/净利 <0.5× 且存货/应收持续膨胀——账面利润被证明无法转化为现金，估值锚整体作废。

## 方法论（统一框架）

1. **现价锚校准**：作废错误/过时股价锚，统一到实时总市值再算安全边际。  
2. **利润脱水**：挤出峰值净利率线性外推、一次性收益、未验证第二曲线。  
3. **压力测试**：产能/折旧、营运资本、地缘/关税、技术路线与竞争格局。  
4. **倍数对齐**：与全球/国内 peer 及自身历史 Band 对齐；拒绝把周期股当永续成长股。  
5. **三情景矩阵 + 概率加权**：Bull/Base/Bear + CIO Memo（Delta / 预期差 / 清仓红线）。

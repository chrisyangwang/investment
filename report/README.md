## 方法论说明

每份报告统一采用如下流程：

1. **现价锚勾稽纠错** — 校验三份文档的当前市值/股本/PE 自洽性，修正错误锚点。
2. **三份原始口径合拢** — 全部归一到 2028E、统一股本（Gemini 原文锚定 2029，按口径直接当 2028 处理）。
3. **CIO 四维审讯挤水分** — 利润率 / 资产减值与现金流 / 产能与供应链 / 估值乘数全球对齐。
4. **终版三情景矩阵** — 营收 × 审定净利率 × 审定 PE → 合理市值与安全边际。
5. **CIO Final Memo** — 核心 Delta、预期差核心胜负手、清仓红线。

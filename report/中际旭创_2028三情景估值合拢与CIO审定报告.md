## 二、CIO 审讯引擎挤水分（四维 Stress Test）

### ① 利润率泡沫（核心挤水点）

- 当前 28.2% 净利率已是周期 + 技术断代双峰值。Claude/WorkBuddy 把 2028 中性净利率放到 28–34%，等于假设“1.6T 红利 + 硅光自给”能在 2028 年继续对抗 ASP 年降 + 新易盛/天孚价格战——逻辑不闭环。
- **裁决**：中性净利率从 28–34% **下压到 25%**（毛利率约 40%，温和回落但硅光自给守住底线）；乐观 27%（守峰值）；悲观 17%（含价格战 + 存货跌价 + 海外厂稼动率拖累）。
- **EML/CW 防线**：EML 占料约 30%，三份文档自测“+10% 成本 ≈ −0.86pp 毛利”是对的，但它们没叠加“涨价 + 转嫁失败”同时发生——这正是悲观 17% 的来源。

### ② 存货/减值审计（悲观情景被低估）

- 存货 126.8 亿、存货/收入 33.2%、521 万只库存（+105% YoY），而 2025 仅计提 ~3 亿（Gemini 口径）/ 累计 ~17 亿（Claude 口径）。口径打架本身就是风险信号。
- 800G→1.6T→3.2T 切换若提前，旧工艺呆滞料 + 专用设备减值是非线性负压。三份在悲观情景几乎都没足额计提 → 在悲观档额外预留约 1 个季度营收级别冲击。

### ③ 产能/关税对冲（拒绝“完美对冲”叙事）

- 泰国/马来/美国基地能解决原产地与合规采购，但解决不了穿透式审查/市场准入这种尾部，且海外厂下行期是成本拖累而非保护。悲观档不给任何对冲加分。

### ④ 估值乘数全球对齐（戳破“市盈率幻觉”）

- 旭创是设计 + 封装 + 组装的模块龙头，不是 NVIDIA（无生态/软件锁定）。Peer 锚：NVIDIA ~30×、Amphenol ~28–32×、Coherent ~15–20×、新易盛 ~25–30×。
- WorkBuddy 的 40–55× 是 2028 年最离谱的水——给一个 2028 年增速已在减速的硬件组装商 55×，等于把周期顶点当永续。**砍掉。**
- **裁决 PE**：Bull 23×（3.2T 周期可见，给 #1 份额溢价）；Base 17×（优质成熟成长硬件）；Bear 11×（回归制造周期框架，戴维斯双杀）。

## 四、CIO Final Memo

### 1. 核心 Delta（相对三份原始版动了什么）

| 维度 | 原始三份区间 | CIO 审定 | 方向 | 逻辑 |
| :--- | :--- | :--- | :--- | :--- |
| 中性净利率 | 27–**34%** | **25%** | 调降 | 拒绝“净利率扩张到 34%”——当前 28% 已是峰值，ASP 年降 + 竞争必致温和回落 |
| 中性营收 | 1,100–2,279 | 1,900 | 居中偏稳 | 取 1.6T 真实放量斜率，但不外推 Claude 的 3,120 极端值 |
| 乐观 PE | 22–**55×** | 23× | 大幅调降 | 砍掉 WorkBuddy 55× 的“AI 基础设施”溢价幻觉 |
| 中性 PE | 17–40× | 17× | 调降 | 锚定 Coherent~新易盛之间，成熟成长硬件 |
| 悲观净利率 | 20–30.6% | 17% | 大幅调降 | 计入价格战 + 存货减值 + 海外厂拖累三杀 |

**一句话**：最大的水不在营收，而在“净利率永续高位”和“PE 永续高倍”两个 β 泡沫。三份里 Claude 营收最虚胖、WorkBuddy 倍数最虚胖、Gemini 反而最接近本结论（方向对，但它营收砍得过狠、PE 也偏低）。

### 2. 预期差核心买点（Not Priced-in 但胜率高）

真正的 Alpha 不是“出货量”（已被充分定价），而是“硅光自给率能否把中性净利率守在 25% 而非市场担心的 ≤22%”。若 2026–2027 季报持续验证硅光占比 >65%、毛利率站稳 44%+，则中性 NP 会上修、估值底抬升——这是 Base 向 Bull 切换的唯一高胜率扳机。当前价已 price-in 此情景，所以它不是“买点”，而是“持有底线验证点”。

### 3. 强制证伪/清仓临界点

1. 单季 1.6T 收入占比掉回 <35%，或北美最大客户（占比 ~24%）单方面砍份额 ≥10% → Bear 路径，强制下修。
2. 综合毛利率跌破 40% + 存货/收入突破 35% 且旧规格显性化 → 触发跌价集中释放，利润表防线被击穿。
3. CPO / 线性直驱(LPO) 或高频铜缆 >15m 突破，结构性绕过可插拔模块 → 估值身份从成长股打回代工股，估值底重置。
4. 泰国基地合规授牌受阻 / 穿透式关税审查 → 不是利润率问题而是准入问题，强制清仓。

## 五、结论

合拢挤水后，当前 1,375 元 / 1.53 万亿已隐含接近“乐观全兑现”的定价——审定中性合理市值仅 ~0.81 万亿（−47%），安全边际为负。CIO 立场与 Gemini 同向（高估），但拒绝 WorkBuddy 的高倍数买入论与 Claude 的净利率扩张假设。

**纪律建议：动态 2028E PE 回落至 ~17×（对应股价 ~720 元区间）before 再行重仓配置；当前价位只做验证、不做加仓。**

## 二、CIO 审讯引擎挤水分（三维 Stress Test + 估值坐标）

### ① 油价中枢与暴烈经营杠杆——不能对抗周期引力

- 业绩对 Brent **高度非线性**：Claude 敏感度 Brent ±$10 ≈ 净利 ±120–160 亿；DeepSeek ±$5 ≈ ±180–220 亿（口径偏大，取中）。特别收益金在高油价年**削峰**，低油价年侵蚀消失——上行凸性弱于「线性桶油利润」卖方模型。
- 2028 mid-cycle：新能源替代 + 非OPEC 供给 → 中枢更可能在 **$65–72**，而非 $80–90。Gemini Bull $90 / DeepSeek Bull 净利 1,880 属地缘溢价情景，不作 Base。
- **裁决**：Base Brent **$68**（略低于 Claude $70、明显高于「永续 $80」幻觉）；Bull **$80**（OPEC+纪律 + 地缘溢价）；Bear **$55**（供大于求，击穿卖方舒适区）。**拒绝「海油可对抗油价大盘引力」**——低成本只改变盈亏平衡，不取消 β。

### ② All-in 成本通胀与深水转固折旧

- 2025 all-in $27.9 是王牌，但：① 渤海等老油田递减抬升单位作业成本；② 圭亚那/巴西深水转固抬升 **DD&A**；③ 油服/钢材/FPSO 通胀。海外 OPEX 已高于中国（~$9+ vs $6.75）。
- 「长期压在 $30 绝对安全线以内」在 Bull/Base 仍可能，但 **Base 不应假设继续下降**；Bear 突破 $31–32 合理。
- **裁决**：Base all-in **$29.5/boe**；Bull **$28.5**（提效对冲）；Bear **$31.5**。产量 Base **840 MMboe**（CAGR ~2.6%，贴公司「盈利性增产」而非冲量）；Bull **865**；Bear **815**。拒绝 Gemini 全情景 890。

### ③ 海外地缘折价

- 海外产量约 31%，圭亚那 Stabroek（25%权益）与巴西盐下是增长极，也是法规/分成/争议敞口。历史海外减值提醒：储量寿命与 FCF 可被一次性击穿。
- **裁决**：Base 给海外增量 **打 70–80 分兑现**（项目延迟常态化）；不因「世纪大发现」叙事上调 PE。Bear：海外权益产量冲击 **−5–8%** 集团产量 + 可能减值数十至百亿。

### ④ 估值坐标——周期采掘地板 vs 国运红利溢价

| 对标 | Forward PE / 特征 | 启示 |
| :--- | :--- | :--- |
| Exxon / Chevron | 常显著高于纯 E&P（综合一体 + 美国上市） | **不可直接对标 14–25×** |
| Shell / 综合油企 | 中枢常低于美股超大盘 | 转型杂音 |
| 中国石油 / 石化 | 炼化缓冲，PE 逻辑不同 | 海油更纯 β |
| 全球纯 E&P mid-cycle | 多在 **6–10×** | 主锚 |
| 高息国央企红利 | 要求 FCF Yield / 股息率 | A 股易溢价、H 股更接近全球 |

- **审判**：2028 时点，市场更可能给「**全球成本左侧 + 刚性分红的高质量周期红利股**」——Base **8.5–9.5×**（取 **9×**），要求前瞻股息率 **~4.5–5%**（A 股口径）。**10–12×** 仅授予 Bull（油价稳在 $75+ 且分红升至 50% 叙事兑现）。**5–7×** 是 Bear 周期地板，不是中性归宿。
- **明确否决 DeepSeek 14–16×**（把海油当永续造血准公用事业）。

## 四、CIO Final Memo

### 1. 核心 Delta（相对四份原始版动了什么）

**一句话**：海油的水不在财务造假（产量、成本、分红均可审计），而在 ①用错误市值锚讲便宜、②把高油价利润当中性、③用 14× PE 对标美股一体化巨头、④低估深水转固后的 DD&A 通胀。

### 2. 市场预期差核心提炼（Consensus Gap）

**正向（尚未完全定价）**：
- **南海深水气 /「油气并举」**：气价相对稳、对冲油价 β；若万亿大气区储量与产量斜率超预期，可小幅抬升估值质量（难改油价主 β）。
- **分红率上修至 50%+ 或特别分红**：净现金厚实，若兑现可强化 H 股类债吸引力——是增强底仓的出牌，不是 A 股翻倍逻辑。
- **H 股相对 A 的折价收敛**：同一 FCF，H 股股息率显著更高——跨市场配置的结构性 Alpha。

**负向（市场可能仍低估）**：
- **A 股已部分定价「成本冠军 + 红利」**：对 $68 mid-cycle 并不便宜。
- **特别收益金对高油价年的削峰**：Bull 利润弹性小于线性外推。
- **海外项目进度与地缘**：产量指引已转保守，市场若仍按 5%+ 产量 CAGR 定价会踩空。

### 3. 投资逻辑证伪临界点（Trigger Point，触发即无条件强制清仓）

1. **Brent/WTI 跌破 $40 且持续超过两个季度**：即使低成本也会出现大额减值、分红失守与估值杀至地板以下。
2. **海外核心油田（圭亚那/巴西等）遭遇法务冻结、分成被极端摊薄或物理封锁**：储量寿命与增长极同时受损。
3. **all-in 成本趋势性突破 $35/boe 且无法用产量结构对冲**：成本护城河叙事破产。
4. **派息率实质性跌破 35% 且无特别分红对冲**：红利底仓逻辑失效。
5. **重大安全/溢油事故导致长时间大面积停产**：经营与 ESG 折价双重打击。

## 五、结论

中国海油是全球成本曲线左侧的纯上游高 FCF 标的，2025 年用产量 +7%、all-in $27.9 验证韧性；分红 45% 构成红利底仓基础。但以 **A 股总市值 14,159 亿**计，审定中性合理市值仅 **~10,620 亿（−25%）**，概率加权 **~10,040 亿（−29%）**——现价更接近油价偏乐观或 PE 偏高的组合，而非深度低估。

**纪律建议**：
- **A 股**：标配偏低；更优买点在 **A 股回落至 ~22–24 元**（对应 Base 带）或 Brent 期货曲线给出更清晰 mid-cycle。
- **H 股**：同逻辑下股息率更优，可作能源红利底仓优先通道；折价扩大时加仓 H、而非追 A。
- 死盯：**Brent 曲线、实现油价贴水、all-in/DD&A、产量指引、特别收益金政策、圭亚那/巴西投产节点、A/H 溢价与派息**。

## 二、CIO 审讯引擎挤水分（Stress Test + 估值坐标）

### ① 海外大储「超额毛利神话」——能守住生存线，守不住 33–38% 永续

- **阶段性高毛利真实存在**：2025 储能海外 ~36GWh（占 ~84%），海外毛利率估 ~38% vs 国内 ~22%。中东大单（沙特 7.8GWh、Masdar 等）支撑能见度。
- **竞争正在结构性加剧**：2026Q1 全球储能排名——比亚迪首次登顶、阳光降至第二、华为新进前三。特斯拉 Megapack 产能释放 + 海博思创/宁德出海 → 海外大储议价权上移。
- **毛利率已剧烈波动**：2025 储能毛利率 ~36%（−1pp）；2025Q4 一度 ~24%，2026Q1 回升至 ~30%——把波峰当稳态是卖方通病。电芯占系统成本 ~60%，碳酸锂反弹可滞后侵蚀毛利。
- **25% 红线**：海外大储分部毛利率跌破 25% → 估值框架从「成长集成商」切换至「普通电气设备」。四份中仅 Gemini 中枢（28–30%）接近现实；Claude/WorkBuddy 33–35%、DeepSeek ~31% 仍偏乐观。
- **裁决**：2028 储能毛利率 Base **28–29%**（Bull 32%、Bear 24–25%）；不给 33–38% 线性外推。PCS 自供可守住相对溢价，守不住绝对超额利润的永续化。

### ② 电网消纳延迟 → 资产质量与 OCF 防线

- 应收 ~235 亿 + 存货 ~273 亿 = **~508 亿**（占总资产 ~42%）。地面大储/EPC 长周期垫资是行业特征，也是隐形杠杆。
- 2025 OCF 169 亿（OCF/NP 1.26×）优异，但 **2026Q1 OCF 仅 ~12 亿**（同比 −33%），经营现金流/净利润仅 ~0.53×——高基数后现金转化脆弱性暴露。
- 2025 集中减值 ~13.8 亿（越南项目 + 长期未开工电站等）说明 EPC/电站资产并非无风险。
- 欧美/拉美 Grid connection 排队 2–3 年 → 已签单延迟交付 → 发出商品积压 + 应收账龄恶化。悲观情景计入：**单项减值/跌价 15–25 亿**。
- **裁决**：不给「OCF/NP 永续 1.2×+」溢价；Base 假设 2028 OCF/NP **0.90–0.95×**；Bear 可击穿至 0.6× 以下并触发仓位纪律。

### ③ 逆变器替换波峰——逻辑成立，斜率远小于叙事

- Wood Mackenzie：全球逆变器 2025 577GWac(−2%) → 2026 523GWac(−9%)，行业总量见顶。
- 替换逻辑成立：逆变器寿命 ~10 年，2015–2018 装机潮 → 2025–2028 进入替换窗。阳光全球第一（25.2%）+ 构网型技术 → 受益方向正确。
- **但 ASP 长期下行不可逆**（组串式年降 3–5%），替换量增 ≠ 收入同比例增。2025 出货 143GW 微降，靠毛利率提升（~31%→35%→Q1 ~40%）对冲——**量缩利升不可永续**。
- DeepSeek 把 2028 逆变器收入做到 ~410 亿、出货 ~217GW——隐含全球份额与总量双升，**过于激进**。
- **裁决**：2028 逆变器出货 Base **155–160GW**（Bull 170、Bear 135–140）；替换贡献增量约 +5–8GW/年，不给 180–217GW 乐观外推。

### ④ 地缘关税墙与海外净利率

- 海外收入占比 ~60%，海外毛利率显著高于国内——这是利润纯度的核心来源，也是脆弱点。
- 美国 IRA/反补贴、欧盟 CBAM、东南亚 AD/CVD 追溯、汇率冲击（2026Q1 汇兑损失 ~4 亿）均可直接削海外 Net Margin。
- **裁决**：Base 海外作为「高毛利引擎但受摩擦税」；Bear：极端关税/本土配额使海外收入占比从 ~60% 降至 ~45%，综合净利率下台阶 2–3pp。

### ⑤ 估值乘数全球对齐——「清洁能源科技平台」还是「高质量电气制造」？

| 对标 | PE 参考 | 特征 | 启示 |
| :--- | :--- | :--- | :--- |
| Enphase | 历史高位 40×+ → 现 ~14–25× | 户用微逆周期股 | 成长溢价可快速蒸发 |
| SolarEdge | 周期低谷可压至 ~10× | 渠道/库存危机后 | 硬件周期杀估值极狠 |
| 锦浪 / 固德威 | 远期多在 12–16× | 组串式同行 | A 股逆变器中枢已下移 |
| Fluence | 常以 PS 定价 | 美国大储集成 | 纯集成商难拿高 PE |
| Tesla Energy | 含在汽车估值内 | Megapack 品牌溢价 | 不可直接对标阳光整体 |

- 股价从 ~155 回落至 ~108 后，TTM PE 从 ~27× 降至 ~16.6×，**历史极端拥挤已部分出清**，但仍高于「周期电气设备」地板（10–13×）。
- 2028 全球光储装机进入高基数、低波动平稳期后，市场更可能把阳光定位为：**享有全球渠道与 PCS 自供溢价的高质量制造龙头**，合理中枢 **14–16× PE**，而非 WorkBuddy/Claude 的 19–25×「科技平台」。
- **裁决**：Base PE **15×**；Bull **18×**（构网型溢价 + AIDC 初步验证）；Bear **12×**（价格战 + 营运资本爆雷）。拒绝 20–25×。PS 交叉：Base ~2.0–2.2×（对标高质量设备，而非纯周期 1.0×）。

### 2. 市场预期差核心提炼（Consensus Gap）

**正向（尚未完全定价的潜在绝杀）**：
- **构网型（Grid-forming）技术溢价**：中东/欧洲弱电网场景下有真实支付意愿，可支撑储能毛利率中枢落在 28–30% 而非坠至 20%——Gemini 方向最对。
- **AIDC / SST / 800V HVDC**：若获英伟达/微软/亚马逊等规模化订单，2027–28 释放 30–50 亿收入、毛利率 50%+，是当前模型几乎零定价的隐形期权。
- **替换周期的「安静增量」**：卖方爱讲叙事，买方更应跟踪替换 GW 与 ASP 的可审计勾稽；一旦替换斜率被订单验证，Base 出货可上修 5–10GW。

**负向（市场仍可能低估）**：
- **比亚迪「电芯+系统」趋势性确立**：纯集成商长期份额从 ~9% 缓降至 7–8% 的路径风险。
- **逆变器行业总量 2025–26 连降**：收入增长过度依赖储能一条腿。
- **营运资本与并网延迟的非线性**：单季减值 >15–20 亿即可改写净利率与 PE 框架。

### 3. 投资逻辑证伪临界点（Trigger Point，触发即无条件强制清仓）

1. **储能毛利率击穿 25%**：连续两季储能系统毛利率 <25% → 海外超额毛利神话破产。
2. **全球份额趋势性失守**：InfoLink 全球储能排名连续两季跌出前三，或与比亚迪/华为差距持续扩大。
3. **营运资本爆雷**：单季应收减值 + 存货跌价合计 >20 亿，或 OCF/NP 连续两季 <0.5×。
4. **极端贸易壁垒**：美欧对中国储能/逆变器启动极端追溯性本土供应链配额，海外收入占比骤降 >15pp。
5. **技术路线颠覆**：全钒液流/钠电/固态等长时储能大规模商业化，使现有锂电大储架构系统性减值。

## 五、结论

阳光电源是全球光伏逆变器第一（25.2%）+ 储能系统集成前二的双龙头，PCS 自供 + 海外渠道构成真实壁垒，2025 年 OCF 169 亿、FCF 139 亿的财务质量在 A 股设备板块首屈一指。**以现价 108 元 / 市值 2,239 亿计，审定中性合理市值 ~2,595 亿（+16%）、概率加权 ~2,465 亿（+10%）**——较旧锚 155 元时的「中性 −22%」已显著改善，但仍远低于四份研报 3,200–4,500 亿的中性目标（因其净利与 PE 双上沿）。

**纪律建议**：可作新能源设备板块**标配/中性偏多**，而非核心超配；仓位死盯储能毛利率、全球出货排名、OCF/NP。若回调至 **~95–100 元**（对应 2028E Base PE ~11–12×）可加仓；若无基本面改善而冲回 **160 元+**（重新透支 19×+），减仓。AIDC 规模化订单公告是切换至 Bull 的硬催化剂。
